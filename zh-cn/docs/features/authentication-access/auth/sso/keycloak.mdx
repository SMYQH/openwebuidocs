本指南介绍如何将 Open WebUI 与 Keycloak 集成以实现 OIDC 单点登录（SSO）。

## 1. 环境准备与端口更改 {#1-environment-preparation-and-port-change}

### Open WebUI 服务器端口 {#open-webui-server-port}
- **默认端口**：`8080`

### Keycloak 端口冲突问题 {#keycloak-port-conflict-issue}
Keycloak 默认也使用 `8080` 端口，导致冲突。请将 Keycloak 端口更改为 `9090`。

```bash
bin/kc.sh start-dev --http-port=9090
```

## 2. 创建 Keycloak Realm {#2-create-a-keycloak-realm}

1. 打开浏览器访问 `http://localhost:9090`，创建管理员账户。
2. 在 `http://localhost:9090/admin` 登录管理控制台。
3. 从顶部的 realm 下拉菜单中，点击 **Add realm**。
4. 输入 `openwebui` 作为 **Realm name**，点击 **Create**。

![创建 realm](/images/features/auth/keycloak/create-realm.png)

## 3. 创建 OpenID Connect 客户端 {#3-create-an-openid-connect-client}

:::info

确保已选中 `openwebui` realm。默认为 `master`。

:::

![选择 realm](/images/features/auth/keycloak/select-realm.png)

1. 确保已选中刚创建的 `openwebui` realm。
2. 在左侧菜单中，点击 **Clients** → **Create client**。
3. 将 **Client ID** 设置为 `open-webui`。
4. 保持 **Client protocol** 为 `openid-connect`。
5. 将 **Access Type** 设置为 `confidential`，点击 **Save**。

![客户端的访问设置](/images/features/auth/keycloak/access-setting-client.png)

## 4. 启用客户端认证并获取凭据 {#4-enable-client-authentication-and-get-credentials}

默认情况下，Keycloak 26.x 将客户端认证设置为"None"，需要手动配置。

1. 进入 **Clients** → **open-webui** → **Settings**。
2. 检查 **Client Authenticator** 下拉菜单。
3. 将"None"更改为 **Client ID and secret**，点击 **Save**。
4. 点击 **Advanced** 选项卡。
5. 在 **Client authentication** 部分，点击 **Reveal secret** 并复制密钥。
6. 在 `.env` 文件中将 `OAUTH_CLIENT_SECRET` 设置为复制的密钥。

## 5. 创建测试用户 {#5-create-a-test-user}

1. 在左侧菜单中，进入 **Users** → **Add user**。
2. 填写 **Username**、**Email** 等信息，点击 **Save**。
3. 点击新创建的用户，进入 **Credentials** 选项卡。
4. 输入新密码，取消勾选 **Temporary**，点击 **Set Password**。
    - *示例：用户名 `testuser`，密码 `Test1234!`*

## 6. 配置 Open WebUI .env 文件 {#6-configure-open-webui-env}

在 `.env` 文件中添加或修改以下变量。

```env

# Enable OAuth2/OIDC Login
ENABLE_OAUTH_SIGNUP=true

# Keycloak Client Information
OAUTH_CLIENT_ID=open-webui
OAUTH_CLIENT_SECRET=<YOUR_COPIED_SECRET>

# OIDC Discovery Document URL
OPENID_PROVIDER_URL=http://localhost:9090/realms/openwebui/.well-known/openid-configuration

# (Optional) SSO Button Label
OAUTH_PROVIDER_NAME=Keycloak

# (Optional) OAuth Callback URL
OPENID_REDIRECT_URI=http://localhost:8080/oauth/oidc/callback
```
**修改 `.env` 文件后，重启 Open WebUI 服务器。**

## 7. HTTP 与 HTTPS {#7-http-vs-https}

-   **HTTP（开发/测试环境）**：
    -   协议：`http://`
    -   示例：`http://localhost:9090`
-   **HTTPS（生产环境推荐）**：
    -   需要为 Keycloak 配置 TLS，或使用在代理端终止 SSL 的反向代理。
    ```bash
    bin/kc.sh start --https-port=9090 \
      --https-key-store=keystore.jks \
      --https-key-store-password=<password>
    ```

## 8. 测试集成 {#8-test-the-integration}

1. 访问 `http://localhost:8080`，页面应显示“Continue with Keycloak”按钮。
2. 点击该按钮，浏览器应跳转至 Keycloak 登录页。
3. 使用 `testuser` / `Test1234!` 登录，浏览器应跳转回 Open WebUI。

## 9. 配置 Keycloak 用户组映射 {#9-configure-keycloak-group-mapping}

### 9.1. 概述 {#91-overview}
默认情况下，Keycloak 客户端的令牌不包含用户组信息。按以下步骤将用户组信息加入令牌。

### 9.2. 找到映射器的创建入口 {#92-locate-mapper-creation}
1. 进入 Keycloak 管理控制台：`http://localhost:9090/admin`。
2. 选择 `openwebui` realm。
3. 导航到 **Clients**，选择 `open-webui` 客户端。
4. 进入 **Client scopes** 选项卡。
5. 选择要承载用户组信息的客户端作用域（例如 `profile` 或 `open-webui-dedicated`）。

    ![选择客户端作用域](/images/features/auth/keycloak/scope-client.png)

6. 在所选作用域的详情页中，打开 **Mappers** 选项卡。

### 9.3. 创建映射器 {#93-create-mapper}
点击 **Create** 或 **Add builtin** 开始创建映射器。

### 9.4. 配置映射器 {#94-mapper-settings}
配置映射器，使令牌包含用户所属的用户组。

![将用户组信息加入令牌的映射器设置](/images/features/auth/keycloak/mappers-setting-group-client.png)

### 9.5. 保存并应用 {#95-save-and-apply}
-   **保存**映射器配置。
-   **重启** Open WebUI 服务器以应用更改。

### 9.6. 配置 Open WebUI 环境变量 {#96-configure-open-webui-environment-variables}
在 `.env` 文件中添加或修改以下变量：

```env

# Enable group synchronization
ENABLE_OAUTH_GROUP_MANAGEMENT=true

# (Optional) Enable Just-In-Time group creation
ENABLE_OAUTH_GROUP_CREATION=true

# The claim key for groups in the token
OAUTH_GROUP_CLAIM=groups
```

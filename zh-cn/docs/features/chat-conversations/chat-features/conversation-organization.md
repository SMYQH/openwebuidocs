# 文件夹与项目 {#folders--projects}

Open WebUI 提供了强大的基于文件夹的组织功能，可将简单的对话容器变成功能完备的**项目工作区**。文件夹不仅让你可以对相关对话进行分组，还可以定义适用于其中所有对话的特定上下文、系统提示词和知识库。

## 文件夹与项目 {#enabling-folders}

### 文件夹与项目

Open WebUI 提供强大的基于文件夹的组织能力，把简单的聊天容器变成功能完备的**项目工作区**。文件夹不仅让你可以对相关的对话分组，还可以定义适用于其中所有聊天的特定上下文、系统提示词和知识库。

## 启用文件夹 {#core-features}

文件夹默认启用。管理员可通过以下方式控制该功能：

- **管理面板**：文件夹功能与其他功能一起进行全局控制
- **环境变量**：[`ENABLE_FOLDERS`](/reference/env-configuration#enable_folders) - 设为 `True`（默认）启用，设为 `False` 禁用

## 核心功能

### 创建文件夹 {#creating-folders}

创建一个新文件夹来组织你的对话：

1. 在**侧边栏**中点击 “聊天” 旁边的 **+ 按钮**，或在聊天列表中右键
2. 选择 **"新建文件夹"**
3. 输入文件夹名称
4. 点击 **保存**

### 将对话移动到文件夹中 {#moving-conversations-into-folders}

你可以把现有聊天整理到文件夹中：

- **拖拽**：在侧边栏中将任意对话拖入某个文件夹
- **右键菜单**：右键某个对话并选择 "移至文件夹"

### 嵌套文件夹 {#nested-folders}

文件夹可以嵌套在其他文件夹中，形成层级结构：

- **从菜单创建子文件夹**：右键（或点击三点菜单 ⋯）任意文件夹，选择 **"创建文件夹"**，即可直接在其中创建子文件夹
- **拖拽**：把一个文件夹拖到另一个文件夹上，即可把它变成子文件夹
- **通过上下文菜单移动**：右键某个文件夹并使用移动选项，将它迁移到另一个父文件夹下
- 文件夹可展开或折叠，以显示 / 隐藏其内容
- 同一父文件夹下，子文件夹名称必须唯一；若输入重复名称，系统会自动追加编号（例如 "Notes 1"）

### 标记为已读和未读 {#unread-badge}

- **将聊天标记为未读**：在侧边栏中打开某个聊天的三点菜单，选择**标记为未读**。该聊天会重新带上圆点，与其它未读聊天一起上移，文件夹计数也会再次增加。用它把某段对话留在你的视野范围内。
- **将文件夹标记为已读**：打开文件夹的三点菜单，选择**全部标为已读**。对于你拥有的文件夹，这会清除该文件夹及其下嵌套的所有未读聊天；对于与你共享的文件夹，则只清除该文件夹本身，并且只清除你在其中的聊天。已归档的聊天不受影响。
- **全部标为已读**：侧边栏的**聊天**区段标题有自己的菜单，其中的**全部标为已读**会清除你拥有的所有未读聊天，散落的和文件夹中的都一样，并一次性清零所有文件夹徽标。同样，已归档的聊天不受影响。

#### 标记为已读和未读 {#marking-read-and-unread}

- **将对话标记为未读**：在侧边栏中打开某个对话的三点菜单并选择 **标记为未读**。该对话会重新显示圆点，与其它未读对话一起上移，文件夹计数也会随之增加。你可以用它在略读之后把某段对话继续留在自己的关注列表中。
- **将文件夹标记为已读**：打开文件夹的三点菜单并选择 **全部标记为已读**。对于你拥有的文件夹，这会清除该文件夹中及其嵌套下的所有未读对话；对于与你共享的文件夹，则只清除该文件夹本身，且只清除其中你自己的对话。已归档的对话不会被处理。
- **全部标记为已读**：侧边栏的 **对话** 区段标题自带菜单，其中的 **全部标记为已读** 会清除你拥有的所有未读对话（散落的对话和文件夹中的对话都包括在内），并一次性清零所有文件夹徽标。已归档的对话同样不会被处理。

### 未读徽标 {#starting-a-chat-in-a-folder}

文件夹会在侧边栏中其名称旁边显示你尚未阅读的内部聊天数量。

- 该计数包含文件夹自身的聊天以及其所有子文件夹中的内容，因此折叠起来的父文件夹依然会显示其下方还等着什么。
- 当一个聊天自你上次打开后发生变化时，它就算作未读。已归档的聊天永远不计入，而仍在生成中的回复要等生成结束后才会计入。
- 打开聊天会立即把它从计数中清除，并且在你打开的每个窗口中都生效：服务器会即时重新计算你的文件夹计数并推送到你的其它会话，而不是等到下次重新加载。
- 未读状态只与你自己的阅读情况有关。共享的文件夹不带徽标，属于他人的聊天无论最近是否被改动过，对你都不会显示为未读。
- 为聊天自动生成的标题不会让它重新变成未读。

文件夹的聊天列表会逐条标注同样的状态：未读对话用一个圆点表示，回复仍在流式生成的用一个加载动画表示。未读聊天排在最前面，每一组按最近活动时间排序，因此等待你的内容会位于文件夹顶部，而不是取决于它的时间戳落在哪里。该列表会在你浏览时保持最新：开始或结束生成的聊天会就地更新并重新排序，新到达文件夹的聊天会被插入而不是触发整页重新加载，连接中断恢复后列表会重新加载。从该列表打开聊天会立即清除它的圆点，无需等待聊天加载完成。

### 在文件夹中开始聊天

当你点击侧边栏中的某个文件夹时，它会成为你的**当前工作区**：

1. 在侧边栏点击任意文件夹将其选中
2. 聊天界面会显示该文件夹当前处于激活状态
3. 此后你新建的任何聊天都会自动创建在该文件夹中
4. 新聊天会**继承该文件夹的设置**（系统提示词与知识库）

## 文件夹设置（项目配置） {#folder-settings-project-configuration}

文件夹可以被配置为完整的项目工作区，拥有独立的 AI 行为和上下文。要编辑文件夹设置：

1. 将鼠标悬停在侧边栏中的某个文件夹上
2. 点击**三点菜单**（⋯）
3. 选择 **"编辑"** 打开文件夹设置弹窗

### 文件夹名称 {#folder-name}

你可以修改文件夹名称，使其更准确地反映用途或项目内容。

### 描述 {#description}

添加一段简短说明，介绍该文件夹的用途。它会显示在文件夹页面的文件夹名称下方，超过两行后被截断。

### 文件夹背景图 {#folder-background-image}

你可以上传背景图来自定义文件夹的视觉外观，从而更直观地区分工作区中的不同项目。

### 默认终端与工作目录 {#default-model}

在**高级**选项下，**默认终端**用于选择该文件夹中新聊天默认使用的终端。选定终端后，**工作目录**用于设置这些聊天在该终端上启动时的路径；留空则使用终端自身的默认值。其文件夹按钮可以浏览该终端的目录，你也可以在其中[克隆 Git 仓库](/features/open-terminal/file-browser#cloning-a-repository)到新文件夹中。选定默认终端后，**默认模型**还会提供该终端的[编码智能体](/features/open-terminal/coding-agents)。这些设置仅对新聊天生效。

### 默认模型 {#default-terminal-and-working-directory}

选择该文件夹中新聊天默认使用的模型，或者保持**使用默认**以回退到你惯用的默认模型。在文件夹中的某个聊天里切换模型不会改变文件夹的默认值；请在此处修改。

### 系统提示词 {#system-prompt}

你可以为文件夹指定专属 **系统提示词**，它会自动应用到该文件夹中的所有对话：

- 该系统提示词会**预置到在此文件夹中新建的每个对话中**
- 这可让 AI 针对特定任务或 persona 采取定制行为
- 系统提示词是可选的；即使不设置，文件夹仍可纯粹用于组织

:::info

只有当你拥有设置系统提示词的权限时（由管理员设置控制），系统提示词字段才会显示。

:::

### 附加知识 {#attached-knowledge}

你可以将**知识库和文件**关联到文件夹：

- 所有关联文件和知识库都会自动作为**上下文**注入该文件夹中的每次聊天
- 这使得该文件夹中的所有对话都具备 RAG（Retrieval Augmented Generation）能力
- 知识库也是可选的；即使不附加文件，文件夹依旧可仅用于组织

## 共享文件夹 {#sharing-folders}

与特定用户或用户组共享文件夹及其中的对话，使团队能够使用同一组对话进行协作。

1. 将鼠标悬停在侧边栏中的文件夹上，打开**三点菜单**（⋯）。
2. 选择**共享**。
3. 添加要共享的用户或用户组，并选择他们的访问级别：
   - **读取**：他们可以打开文件夹并阅读其中的对话。
   - **写入**：他们还可以重命名文件夹、添加对话并在其中创建子文件夹。
4. 保存。

共享的文件夹会出现在接收方的侧边栏中。以下是一些规则：

- **子文件夹继承共享设置。** 对文件夹授予的访问权限会级联到其嵌套的所有内容。
- **只有所有者或管理员可以删除共享的根文件夹**或更改共享对象。具有写入权限的用户可以添加和编辑对话与子文件夹，但不能删除共享文件夹本身。
- **文件夹不能公开共享。** 共享始终针对特定用户或用户组，没有公开链接。

文件夹共享受**文件夹共享**权限控制，默认关闭。管理员可在**管理面板 > 用户 > 用户组 > 权限**中按组启用，或通过 [`USER_PERMISSIONS_FOLDERS_ALLOW_SHARING`](/reference/env-configuration#user_permissions_folders_allow_sharing) 设置默认值。

## 示例用例 {#example-use-case}

:::tip **创建一个 “Python Expert” 项目**

假设你正在进行一个 Python 开发项目：

1. **创建一个文件夹**，命名为 "Python Expert"
2. **编辑该文件夹**，并设置系统提示词：

       You are an expert Python developer. You provide clean, efficient, and well-documented code. When asked for code, prioritize clarity and adherence to PEP 8 standards.

3. **附加知识**，例如关联你项目的技术规格 PDF 或库文档
4. **点击该文件夹**，将其设为当前激活工作区
5. **开始聊天** —— 每个新对话都会自动具备：
   - Python 专家角色
   - 访问项目文档的能力
   - 自动归档到该文件夹中

:::

## 标签（补充性组织方式） {#tags-complementary-organization}

除文件夹外，**标签**也提供了一种灵活的对话标记方式：

- **添加标签**：根据内容或用途，为对话添加关键词标签
- **按标签搜索**：通过搜索功能按标签筛选对话
- **灵活组织**：标签可随时添加或移除，且不会影响文件夹结构

:::tip **按主题打标签**

如果你经常讨论“marketing”或“development”等主题，可以用这些词给对话打标签。这样当你搜索某个标签时，无论这些对话位于哪个文件夹，都能被快速找到。

:::

### 开启社区共享 {#enabling-community-sharing}

要开启社区共享，请按以下步骤操作：

1. 以 **管理员** 身份进入 **管理面板** 页面。
2. 点击 **设置** 标签页。
3. 在 **通用** 设置标签页中打开 **社区共享**。

:::note

**注意：** 只有管理员可以切换 **社区共享** 选项。如果该选项被关闭，用户和管理员都不会看到用于分享对话的 **分享到 Open WebUI 社区** 选项。社区共享必须由管理员开启，用户才能把对话分享到 Open WebUI 社区。关闭它时，导入模型上的 openwebui.com 作者链接也会一并隐藏。

:::

这会为你的 Open WebUI 实例上的所有用户开启社区共享。

### 分享聊天 {#sharing-chats}

要分享一个聊天：

1. 选中你想分享的聊天对话。
2. 将鼠标悬停在目标聊天上方，点击出现的 3 点菜单。在触摸屏上 3 点菜单始终可见，直接点按即可。
3. 点击 **分享** 选项。
4. 选择 **分享到 Open WebUI Community**（需要**管理员**在 **设置 > 通用 > 功能** 中开启 **社区共享**；创建任何分享链接还需要 **允许聊天分享** 权限，即 `USER_PERMISSIONS_CHAT_SHARE`）或 **复制链接**。

:::info 分享范围由 RBAC 控制

弹窗中会显示一个 **访问控制** 选择器，用于决定谁可以打开该链接，其中提供 **私密**、**公开** 和 **开放**，还可以指定具体的用户和用户组。新建的链接默认为私密；如果该聊天还没有链接，授予他人访问权时就会创建链接。

**公开**会让本实例中任何已登录的用户都能访问该链接，因此未登录的访客仍会被引导到登录页。它受 **聊天公开分享** 权限控制。该权限关闭时，非管理员用户只能看到将访问权限授予特定用户或用户组的选项；管理员始终保留全部选项。配置方式见 [RBAC 权限](/features/authentication-access/rbac/permissions) 和 [`USER_PERMISSIONS_CHAT_ALLOW_PUBLIC_SHARING`](/reference/env-configuration#user_permissions_chat_allow_public_sharing)。

**开放**则完全取消登录要求，详见下文的[开放链接](#open-links-no-sign-in)。

:::

### 开放链接（无需登录） {#open-links-no-sign-in}

**开放**是唯一能让聊天在没有 Open WebUI 账户的情况下被阅读的设置。任何持有该链接的人都可以直接从互联网上阅读这段对话，无需登录，也不会留下谁查看过的记录。

它默认关闭。非管理员需要**聊天开放共享**权限（[`USER_PERMISSIONS_CHAT_ALLOW_OPEN_SHARING`](/reference/env-configuration#user_permissions_chat_allow_open_sharing)，默认 `False`），该选项才会出现。没有该权限时，下拉框只显示**私密**和**公开**，服务器也会拒绝开放授权。

开放链接能做什么、不能做什么：

- 它是只读的。开放访问只以读取授权的形式存在，因此不会提供写入开关，针对它的写入授权也会被拒绝。
- 它只适用于聊天。没有其它资源类型接受这种授权，因此知识库、模型、提示词、工具、笔记和日历都无法用这种方式共享。
- 把该对话复制到自己的账户中，仍然需要登录并拥有**聊天导入**权限。
- 页面会请求搜索引擎不要索引它（`noindex,nofollow`）。这只是对守规矩的爬虫提出的请求，并非访问控制：该链接对任何拿到它的人仍然有效。

:::warning 开放链接对整个互联网公开

请把 URL 本身视为唯一的保护手段。它无法有选择地吊销，因此一旦泄露，切断访问的方式是删除该分享链接（参见[删除已分享聊天](#deleting-shared-chats)）或把聊天改回**私密**。共享聊天是快照，因此生成链接那一刻对话中的内容会持续可见，包括消息中引用的任何文件内容、名称或内部细节。

:::

#### 分享到 Open WebUI Community {#sharing-to-open-webui-community}

当你选择 `分享到 Open WebUI Community` 时：

- 会打开一个新标签页，让你把聊天以快照形式上传到 Open WebUI 社区网站：https://openwebui.com/chats/upload
- 你可通过以下权限设置控制谁可以查看已上传的聊天：
  - **私密**：只有你自己可以访问
  - **公开**：互联网中的任何人都可以查看该聊天快照中展示的消息
  - **公开，完整历史记录**：互联网中的任何人都可以查看该聊天的完整重生成历史

:::note

注意：你可以随时在社区平台上的 openwebui.com 账号中修改已分享聊天的权限级别。

**当前，社区网站上的已分享聊天还不能通过搜索发现。不过后续更新计划支持：当权限为 `Public` 或 `Public, Full History` 时，公开聊天可被公众发现。**

:::

#### 复制分享链接 {#copying-a-share-link}

当你选择 `复制链接` 时，系统会生成一个唯一的分享链接，你可以把它发送给其他人。

**重要说明：**

- 被分享的聊天只会包含创建链接当时已有的消息。生成链接后，如果聊天里新增了消息，这些新消息不会自动包含进去，除非你删除旧链接并重新生成新链接
- 生成的分享链接本质上是该聊天在生成时刻的静态快照。启用[允许回复](#allowing-replies)后，被你共享的人会看到实时聊天。
- 除非该聊天被设为**开放**，查看它需要拥有生成链接那个 Open WebUI 实例上的账户，并已登录该账户。未登录的访客会先被重定向到登录页。
- 设为**开放**的聊天无需满足以上两个条件，任何拿到链接的人都能阅读。参见[开放链接](#open-links-no-sign-in)。

### 允许回复 {#allowing-replies}

一旦至少有一个人或用户组拥有访问权限，模态框中还会显示**共享模式**：

- **仅克隆**（默认）：他人打开链接后看到的是创建或最后更新链接时的对话。若要继续，他们需要把它克隆或分叉到自己的聊天中（参见[克隆或分叉已分享的聊天](#cloning-or-forking-a-shared-chat)）。
- **允许回复**：经单独授权、通过用户组或**公开**获得访问权的每个人都可以向同一个聊天中写入内容。打开链接会直接进入实时对话，聊天中的每个人都能看到新消息和回复的到达。

![共享聊天对话框，共享模式设置为允许回复，访问名单中包含 Engineering 用户组](/images/features/chat/share-allow-replies.webp)

在允许回复的聊天中：

- 在气泡布局下，其他人的消息显示在左侧并带有姓名和头像，自己的消息显示在右侧且不带这些信息。在**设置 > 界面**中关闭**聊天气泡界面**后，每条消息都会显示发送者的姓名和头像。
- 消息输入框上方的一行会显示谁正在输入。
- 聊天顶栏会显示当前打开该聊天的其他人。点击此处可打开**协作者**列表。
- 任何能向该聊天写入且拥有**允许重新生成回复**权限的人都可以**重新生成**任意回复。新版本归生成它的人所有。每个人只能继续、停止和评价自己生成的回复版本。
- 任何能向该聊天写入且拥有[**允许编辑聊天**](/features/authentication-access/rbac/permissions#3-chat-permissions)权限的人都可以编辑任意提示词。编辑器提供**发送**选项，它会把编辑后的提示词连同一条新回复作为一个新分支加入，并保持原分支不变。聊天中的其他人仍停留在他们原先选中的分支上。
- 只有所有者可以编辑回复并就地保存修改，而且只能针对自己的消息和自己生成的回复版本。在他人的消息上打开编辑器时，提示词提供**发送**、回复提供**另存为副本**，它们会新增一条消息并保持原消息不变。
- 回复上的**删除**只对所有者可见，且仅在该回复拥有多个版本时才可对所有者生成的回复版本使用。
- 有权在聊天中发消息的人都可以更改并保存该聊天的模型、终端和工作文件夹，也都可以使用该聊天自己的终端。
- 只有所有者的消息会生成标题和标签，或改变聊天的附加文件和聊天变量。其他人的发言不会使用该聊天的变量。
- 仅通过**开放**链接进入该聊天、未通过单独授权、用户组或**公开**获得访问权的人看到的是快照。
- 当有人失去访问权限时，聊天会立即对他关闭，他也不再收到该聊天的更新。

![聊天所有者看到的允许回复的聊天：另一位成员的消息及其姓名和头像、模型对它的回答，以及输入框上方显示该成员正在输入的一行](/images/features/chat/shared-chat-replies-live.webp)

切回**仅克隆**会刷新链接背后的快照，因此它随后显示的是当时的对话，包括回复在内。[**允许聊天分享**](/features/authentication-access/rbac/permissions#3-chat-permissions)权限控制谁可以分享聊天，访问选项与任何分享链接遵循相同的权限。[共享文件夹](/features/chat-conversations/chat-features/conversation-organization#sharing-folders)具有同样的**共享模式**，作用于直接位于该文件夹中的聊天。每个子文件夹都有自己的共享模式。

### 查看已分享聊天 {#viewing-shared-chats}

要查看已分享聊天：

1. 确保你已登录到生成该分享链接的 Open WebUI 实例账户。这一步不适用于以**开放**方式共享的聊天，任何人都无需账户即可阅读。
2. 点击分享给你的链接。
3. 聊天会以只读形式显示。启用[允许回复](#allowing-replies)后，你会直接进入该聊天并可以向其中写入内容。
4. 如果生成该分享链接的 Open WebUI 实例管理员已配置文本转语音，则消息旁可能会显示朗读按钮（视具体情况而定）。

属于他人的聊天会显示在其作者名下，每条消息都带有发送者的姓名和头像。通过共享链接、[与你共享的文件夹](/features/chat-conversations/chat-features/conversation-organization#sharing-folders)或管理员的**管理面板 > 用户**打开时，都是如此。在应用内打开时，聊天的**概览**标签页也会以同样的方式标注消息节点。

除所有者之外的任何人只拿到对话本身：所有者的高级参数、选中的工具、工具服务器和过滤器、聊天变量以及单条消息设置仍只有所有者可以访问。

#### 克隆或分叉已分享的聊天 {#cloning-or-forking-a-shared-chat}

只要你能阅读某个属于他人的聊天，就可以把它复制到自己的聊天中：通过分享链接、共享给你的授权、[与你共享的文件夹](/features/chat-conversations/chat-features/conversation-organization#sharing-folders)，或者对管理员而言的**管理面板 > 用户**。有两种方式：

- **克隆聊天**，即聊天底部的按钮，会把该对话复制到你自己的聊天中，位于任何文件夹之外。当该聊天对你而言是只读时它会显示；在允许回复的聊天中请使用**分叉聊天**。
- **分叉聊天**，即每条已完成回复下方的操作，会把从开头到该回复为止的对话复制到一个新聊天，标题为 `<original title> (fork)`。

两者都要求你已登录并拥有[**允许聊天导入**](/features/authentication-access/rbac/permissions#3-chat-permissions)权限（管理员始终拥有）。由分享链接产生的分叉只包含链接所展示的内容，因此在链接最后更新后添加到原聊天的消息不会出现在其中。对他人聊天的分叉会进入你自己不属于任何文件夹的聊天，并且不包含所有者的置顶、标签、聊天设置和聊天变量。

在副本中，原所有者的提示词和回复变成了你的，因此你可以像在自己的任何聊天中一样编辑它们，并对它们使用**重新生成**和**继续回复**。在允许回复的聊天中由其他人写下的消息仍保留其作者。

使用**仅克隆**时，分享链接打开的页面只显示消息，没有 **Artifacts** 面板，因此回复中的 HTML 和 SVG 代码不会在那里作为 artifact 打开。要在自己的副本中查看这些 artifact，请克隆或分叉该聊天。

#### 将已分享的聊天作为上下文 {#using-a-shared-chat-as-context}

对某个对话的读取权限还让你可以把它附加到自己的某个对话中，从而让模型基于它开展工作。这涵盖了单独授权给你的对话、共享给你所属用户组的对话、设置为 **公开** 的对话，以及位于[与你共享的文件夹](/features/chat-conversations/chat-features/conversation-organization#sharing-folders)中的对话。
模型接收的是该对话当前的样子，因此自链接生成以来新增的消息也会包含在内，尽管链接本身仍提供的是较旧的快照。只有该对话当前所处的分支会被一并传入。文本会原样传入，不做切块，也不做向量检索。

### 更新已分享聊天 {#updating-shared-chats}

要更新已分享聊天：

1. 选中你想分享的聊天对话
2. 将鼠标悬停在目标聊天上方，点击出现的 3 点菜单。在触摸屏上 3 点菜单始终可见，直接点按即可。
3. 点击 **分享**
4. 如果你之前分享过该聊天，**分享聊天** 弹窗的显示会有所不同

**分享聊天** 弹窗包含以下选项：

- **之前**：在新标签页打开此前通过分享链接分享出去的聊天
- **删除此链接**：删除该聊天当前的分享链接，并恢复到初始分享弹窗
- **分享到 Open WebUI Community**：打开新标签页进入 https://openwebui.com/chats/upload 并自动带上当前聊天快照
- **更新并复制链接**：更新此前分享链接对应的聊天快照，并将该链接复制到设备剪贴板

### 删除已分享聊天 {#deleting-shared-chats}

要删除分享链接：

1. 选中你想删除分享链接的聊天对话
2. 将鼠标悬停在目标聊天上方，点击出现的 3 点菜单。在触摸屏上 3 点菜单始终可见，直接点按即可。
3. 点击 **分享**
4. 如果你之前分享过该聊天，**分享聊天** 弹窗的显示会有所不同
5. 点击 **删除此链接**

删除后，该分享链接将立即失效，其他用户将无法再查看该聊天。

:::note

**注意：** 分享到社区平台的聊天无法删除。如需修改社区平台上某个聊天的访问权限：

:::

1. 登录你在 openwebui.com 上的 Open WebUI 账号
2. 点击网站右上角的账号用户名
3. 点击 **聊天**
4. 打开你要修改权限的聊天
5. 滚动到聊天底部并更新其权限级别
6. 点击 **更新聊天**

### 管理已分享聊天 {#managing-shared-chats}

Open WebUI 提供了一个集中式面板，用于管理你分享过的所有聊天对话。你可以在其中搜索分享历史、重新复制链接，或立即撤销访问权限。

有关该管理面板的详细说明，请参阅 [已分享聊天管理](/features/chat-conversations/data-controls/shared-chats)。

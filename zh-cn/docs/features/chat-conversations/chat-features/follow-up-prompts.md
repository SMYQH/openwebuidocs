# 追问提示 {#follow-up-prompts}

Open WebUI 可以在每次模型响应后自动给出后续消息建议。这些建议会以可点击的标签形式显示在回复下方，帮助你无需重新输入提示词，就能进一步探索话题。

使用内置提示词时，每条建议都写成你可能接着发出的消息，可以是问题或请求。最值得追问的一条排在首位。管理员可以在管理员区域的**设置 > 界面**中修改 **Follow Up Generation Prompt**，也可以通过 [`FOLLOW_UP_GENERATION_PROMPT_TEMPLATE`](/reference/env-configuration#follow_up_generation_prompt_template) 替换内置提示词。

## 设置 {#settings}

你可以在 **设置 > 界面** 的 **聊天** 区域中配置追问提示行为：

### 自动生成追问 {#follow-up-auto-generation}

**默认：开启**

会在每次模型响应后自动生成后续建议。这些建议由 [任务模型](/reference/env-configuration#task_model) 根据当前对话上下文生成。

- **开启**：每次模型响应后都会生成追问提示
- **关闭**：不生成任何追问建议

该开关仅在管理员于 **设置 > 界面**（管理员区域） 中开启 **Follow Up Generation** 时显示。在它被隐藏期间，你的选择会被保留，并在管理员重新开启生成后再次生效。下面的两个设置无论开关是否显示都保持可见，因为它们同样适用于已经保存在聊天中的追问。

### 在聊天中保留追问提示 {#keep-follow-up-prompts-in-chat}

**默认：关闭**

默认情况下，追问提示只会出现在最近一条消息下方；当你继续对话后，它们就会消失。

- **开启**：追问提示会被保留，并持续显示在聊天历史中的所有消息下
- **关闭**：只有最后一条消息会显示追问提示

:::tip 非常适合知识探索
当你在探索知识库时，可以开启此设置。这样你能看到之前每条回复对应的所有推荐追问，便于回溯并尝试不同的信息探索路径。
:::

### 将追问插入输入框 {#insert-follow-up-prompt-to-input}

**默认：关闭**

控制你点击追问提示后会发生什么。

- **开启**：点击追问后，会先把文本插入输入框，你可先编辑再发送
- **关闭**：点击追问后，会立即作为下一条消息发送

## 用 Tab 键选中 {#taking-one-with-tab}

回复生成完毕后，第一条追问也会以灰色提示文字显示在空白输入框中。按 **Tab** 将它填入输入框，然后编辑或发送。输入其他内容就会隐藏灰色提示，不会影响你撰写消息。

它只在消息框为空、且最后一条消息是已完成的回复时显示，并且模型一开始重新生成就会消失。回复下方的标签保持不变，这与其中第一条是同一条建议。

## 重新生成追问 {#regenerating-follow-ups}

要为某条回复重新生成追问建议，可以使用社区提供的[重新生成追问](https://openwebui.com/posts/9b5ac6d6-dfd6-4cad-bc1d-5518b138f22d)操作按钮。

Open WebUI 提供一个集中式面板，用于管理你分享出去的所有聊天对话。借助这一功能，用户可以审查已共享内容，并在需要时快速撤销访问权限。

:::info
本页记录的是共享聊天的**管理面板**。如果你想了解如何分享聊天，请参阅 [聊天分享](/features/chat-conversations/chat-features/chatshare)。
:::

## 进入管理面板 {#accessing-the-management-dashboard}

1. 点击侧边栏左下角的**个人资料名称**或头像。
2. 在菜单中选择 **设置**
3. 进入 **数据控制** 标签
4. 找到 **共享聊天** 这一行并点击 **管理** 按钮

## 面板功能 {#dashboard-features}

**共享聊天** 弹窗为你已分享的聊天提供统一管理界面：

- **集中列表**：查看所有仍具有有效分享链接的对话
- **搜索与筛选**：按标题快速查找特定的共享聊天。
- **高级排序**：你可以按以下方式整理分享历史：
  - **更新时间**（默认）
  - **标题**
- **复制链接**：点击任意条目旁的 **剪贴板图标**，即可立即将分享 URL 复制到剪贴板
- **撤销访问（取消共享）**：点击 **取消共享图标**（带斜杠的链接图标）即可停用分享链接
  - :::warning
    撤销访问后，链接立即失效，任何访问该 URL 的人都会被重定向到首页，未登录时则会被重定向到登录页。如果分享时启用了[允许回复](/features/chat-conversations/chat-features/chatshare#allowing-replies)，收件人也会失去对聊天本身的访问权限。此操作不可撤销，但可在主界面重新分享该聊天，生成一个*新的*唯一链接。
    :::
- **分页**：列表每次加载 60 条，滚动到底部时会自动获取下一批。底部的 **取消共享全部聊天** 按钮可在确认后一次性撤销所有链接。

## 常见问题 {#faq}

**Q：取消分享聊天会删除原始对话吗？**  
**A：** 不会。取消分享只会删除公开链接，你原本的聊天历史会完整保留。

**Q：我能在这里管理自己分享到社区平台的聊天吗？**  
**A：** 不能。该面板只管理你本地实例生成的分享链接。对于分享到社区平台的内容，请参阅 [删除已分享聊天](/features/chat-conversations/chat-features/chatshare#deleting-shared-chats)。

**Q：如果我删除原始聊天，会对分享链接产生什么影响？**  
**A：** 删除聊天会立即使所有关联的分享链接失效并删除这些链接。删除文件夹时一并删除的聊天也适用。

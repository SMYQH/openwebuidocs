Open WebUI 允许你将对话归档，这样既能保留它们供日后参考，又能让侧边栏保持整洁。**已归档聊天** 面板让你可以集中管理所有已归档对话。

## 进入已归档聊天 {#accessing-archived-chats}

1. 点击侧边栏左下角的**用户名**或头像
2. 在菜单中选择 **设置**
3. 进入 **数据** 下的 **已归档聊天** 标签

已归档聊天过去藏在 **数据控制** 标签里的 **管理** 按钮后面；现在它们在同一个 **数据** 分组中有了自己的标签页。

## 面板功能 {#dashboard-features}

**已归档聊天** 视图提供以下管理能力：

- **搜索**：通过标题快速查找已归档聊天
- **恢复**：将已归档聊天恢复到主侧边栏。归档单个聊天会把它从所在文件夹中移除，并停止仍在生成的回复；恢复不会把它放回该文件夹。
- **删除**：从你的账号中永久移除某个已归档聊天

## 批量操作 {#bulk-operations}

在数据控制标签中，你还可以执行批量操作：

- **归档所有聊天**：一次性将当前所有对话归档，适合定期整理
- **删除所有聊天**：永久删除所有对话（活动和已归档的都有），以及你创建的所有分享链接。上传到这些聊天的文件和在其中生成的图片不会被删除，请在 **管理文件** 中移除它们。
  - :::warning
    该操作无法撤销。所有聊天历史都会被永久删除。
    :::

:::info 删除需要聊天删除权限

已归档聊天上的 **删除** 和 **删除所有聊天** 只会为拥有 **允许聊天删除** 权限的人显示。没有该权限时两者都不会出现，因此不会出现按下却拒绝执行的按钮，归档与 **取消归档全部** 的行为也会保持不变。管理员始终不受此限制。参见[权限](/features/authentication-access/rbac/permissions#3-chat-permissions)。

:::

:::info 管理员可隐藏归档入口

管理员可以在[可见控件](/features/administration/interface-defaults#hiding-controls)中隐藏 **归档** 入口，这也会一并隐藏取消归档。已归档的聊天仍可在此处打开和删除。

:::

## 常见问题 {#faq}

**Q：我可以在已归档聊天里搜索内容吗？**  
**A：** 可以。归档面板自身按聊天标题搜索。在聊天输入框 **+** 菜单中的 **参考对话** 选择器，以及搜索窗口（`Cmd+K` / `Ctrl+K`），都可以在加上 `archived:true` 过滤条件后读取已归档聊天的消息，例如 `archived:true quarterly report`。无需先恢复聊天就能在其中搜索。参见[历史记录与搜索](/features/chat-conversations/chat-features/history-search#filter-prefixes)。

**Q：可归档聊天数量有限制吗？**  
**A：** 没有硬性上限。可扩展性取决于你的数据库配置。

**Q：已归档聊天还会占用存储空间吗？**  
**A：** 会。已归档聊天仍然保存在数据库中。若想释放空间，需要将其永久删除。

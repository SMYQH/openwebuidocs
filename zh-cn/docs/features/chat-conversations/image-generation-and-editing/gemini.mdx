Open WebUI 也支持通过 **Google AI Studio API**（也称 **Gemini API**）进行图像生成。

### 初始设置 {#initial-setup}

1. 从 Google AI Studio 获取一个 [API key](https://aistudio.google.com/api-keys)——或者从 Google Cloud 获取 API key，并为项目启用 `Generative Language API`
2. 大多数情况下，你还需要创建项目、启用 `Generative Language API` 并配置计费信息，因为图像生成 API 不是免费提供的

:::warning
如果你使用的是免费 API key，请务必在账户中绑定支付方式。缺少有效支付方式是配置过程中最常见的报错原因之一。
:::

:::tip
如果你使用的是 Vertex AI，也可以在 Google Cloud 中创建 API key，而不是 service account。只要它具备正确权限，并且项目已启用 Generative Language API，这个 key 同样可正常工作。
:::

### 配置 Open WebUI {#configuring-open-webui}

1. 在 Open WebUI 中前往 **Settings** > **Images**（管理员区域）
2. 将 `Image Generation Engine` 设置为 `Gemini`
3. 将 `API Base URL` 设置为 `https://generativelanguage.googleapis.com/v1beta`
4. 输入你的 Google AI Studio [API key](https://aistudio.google.com/api-keys)
5. 输入你想使用的模型名称，可以是 [Imagen 模型](https://ai.google.dev/gemini-api/docs/imagen#model-versions)，也可以是 [Gemini 模型](https://ai.google.dev/gemini-api/docs/image-generation)
6. 将 `Gemini Endpoint Method` 设为与该模型匹配的值：Imagen 用 `predict`，Gemini 用 `generateContent`

:::info

Imagen 模型和 Gemini 模型由不同的端点提供，因此 **Gemini 端点方法**必须与你填写的模型相匹配。

Imagen 模型使用 `predict`：

- `https://generativelanguage.googleapis.com/v1beta/models/imagen-4.0-generate-001:predict`。
- [Imagen 模型文档](https://ai.google.dev/gemini-api/docs/imagen)

Gemini 模型使用 `generateContent`：

- `https://generativelanguage.googleapis.com/v1beta/models/gemini-3-pro-image:generateContent`。
- [Gemini 模型文档](https://ai.google.dev/gemini-api/docs/image-generation)

如果端点方法留空，会回退到 `predict`，因此像 `gemini-3-pro-image` 这样的 Gemini 模型在你切换到 `generateContent` 之前都会失败。

`400: [ERROR: models/gemini-3-pro-image is not found for API version v1beta, or is not supported for predict. Call ListModels to see the list of available models and their supported methods.]`

:::

### 使用 Gemini Endpoints 的 LiteLLM Proxy {#litellm-proxy-with-gemini-endpoints}

Open WebUI 支持通过使用 Gemini 或 Imagen 端点的 LiteLLM 代理进行图像生成。配置方式如下：

1. 在 Open WebUI 中前往 **Settings** > **Images**（管理员区域）
2. 将 `Image Generation Engine` 设置为 `Open AI`
3. 将 API endpoint URL 改为 `https://<your-litellm-url>:<port>/v1`
4. 输入你的 LiteLLM API 密钥
5. API version 可留空
6. 输入你在 LiteLLM 配置中使用的图像模型名称
7. 将图像尺寸设置为所选模型支持的可用尺寸之一

:::tip

若要查看 LiteLLM 连接信息，请前往 **Settings** > **连接**（管理员区域）。
你的连接信息会显示在 Gemini API 连接下方。

:::

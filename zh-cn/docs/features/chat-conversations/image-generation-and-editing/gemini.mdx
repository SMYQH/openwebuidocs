Open WebUI 也支持通过 **Google AI Studio API**（也称 **Gemini API**）进行图像生成。

### 初始设置 {#initial-setup}

1. 从 Google AI Studio 获取 [API 密钥](https://aistudio.google.com/api-keys)，或从 Google Cloud 获取 API 密钥并为项目启用 `Generative Language API`。
2. 大多数情况下，你还需要创建项目、启用 `Generative Language API` 并配置计费信息，因为图像生成 API 不是免费提供的

:::warning
如果你使用免费 API 密钥，请务必在账户中添加支付方式。缺少有效支付方式是配置失败的常见原因。
:::

:::tip
使用 Vertex AI 时，也可以在 Google Cloud 中创建 API 密钥，而不必创建服务账号。为密钥授予相应权限，并在项目中启用 Generative Language API 后，即可使用该密钥。
:::

### 配置 Open WebUI {#configuring-open-webui}

1. 在 Open WebUI 中前往**设置** > **图像**（管理员区域），添加连接。
2. 将**连接类型**设为 **Gemini**。
3. 将 **URL** 设为 `https://generativelanguage.googleapis.com/v1beta`。
4. 输入你的 Google AI Studio [API 密钥](https://aistudio.google.com/api-keys)。
5. 在 **Model IDs** 中添加要用的[Imagen 模型](https://ai.google.dev/gemini-api/docs/imagen#model-versions)或 [Gemini 模型](https://ai.google.dev/gemini-api/docs/image-generation)。
6. 打开**高级**，将**端点方法**设为与模型对应的值：Imagen 使用 `predict`，Gemini 使用 `generateContent`。
7. 设置**访问控制**并点击**保存**。未授予访问权限时，只有管理员能使用该连接。

:::info

Imagen 和 Gemini 模型使用不同的端点，因此**端点方法**必须与填写的模型匹配。

Imagen 模型使用 `predict`：

- `https://generativelanguage.googleapis.com/v1beta/models/imagen-4.0-generate-001:predict`。
- [Imagen 模型文档](https://ai.google.dev/gemini-api/docs/imagen)

Gemini 模型使用 `generateContent`：

- `https://generativelanguage.googleapis.com/v1beta/models/gemini-3-pro-image:generateContent`。
- [Gemini 模型文档](https://ai.google.dev/gemini-api/docs/image-generation)

保留默认值时会使用 `predict`，因此 `gemini-3-pro-image` 等 Gemini 模型会出错，改为 `generateContent` 后即可使用。

`400: [ERROR: models/gemini-3-pro-image is not found for API version v1beta, or is not supported for predict. Call ListModels to see the list of available models and their supported methods.]`

:::

### 通过 LiteLLM 代理使用 Gemini 端点 {#litellm-proxy-with-gemini-endpoints}

提供 Gemini 或 Imagen 模型的 LiteLLM 代理应添加为**兼容 OpenAI** 的连接。见 [LiteLLM 代理](/features/chat-conversations/image-generation-and-editing/openai#litellm-proxy-with-openai-endpoints)。

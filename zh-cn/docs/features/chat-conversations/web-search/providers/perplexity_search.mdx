## Perplexity 搜索 API {#perplexity-search-api}

:::info

Perplexity Search API 只是一个搜索引擎接口，而 Perplexity 集成则是直接使用 Perplexity 的模型（并结合其网页搜索能力）。

:::

### 设置 {#setup}

1. 前往：`Settings` -> `Web Search`（管理员区域）
2. 打开 `Enable Web Search`
3. 将 `Web Search Engine` 从下拉框中设为 `perplexity_search`
4. 输入你从 [Perplexity API 密钥管理](https://www.perplexity.ai/account/api/keys) 页面获取的 Perplexity API 密钥。
5. 点击保存

### 使用 LiteLLM 作为搜索后端 {#using-litellm-for-search}

你也可以使用 [LiteLLM](https://docs.litellm.ai/) 代理实例来作为搜索提供商，而不是直接连接 Perplexity。LiteLLM 的 `/search` 端点与 Open WebUI 使用的 Perplexity Search API 风格兼容。

配置方式如下：

1. 按照上面的步骤操作，并将引擎设为 `perplexity_search`
2. 在 **Perplexity Search API URL** 字段（`PERPLEXITY_SEARCH_API_URL`，默认 `https://api.perplexity.ai/search`）中，把默认值替换为你的 LiteLLM 端点。该字段填写的是完整的搜索端点，而不是基础 URL
3. URL 必须遵循以下格式：`http://<your-litellm-url>/search/<your-search-provider-name>` —— 请确保其中的提供商名称与 LiteLLM 配置中定义的名称完全一致

**示例：**

如果你的 LiteLLM 实例运行在本机，并且你想使用在 LiteLLM 配置中定义的 `perplexity-search` 提供商：

```
http://localhost:4000/search/perplexity-search
```

网络搜索让 AI 在线查找信息，以帮助回答你的问题。

其中包含两项任务：**查找页面** 和 **阅读页面**。**搜索引擎负责查找页面**，**网页加载器负责读取页面**。

## 搜索引擎与网页加载器 {#search-engine-vs-web-loader}

可以把它想象成在线查找菜谱。你在 Google 中输入“巧克力蛋糕食谱”，然后点击某个结果来阅读食谱。这是两个独立的步骤。Open WebUI 做的事情与之类似：

| 设置 | 作用 | AI 得到什么 |
| --- | --- | --- |
| **网页搜索引擎** | 搜索“巧克力蛋糕食谱”。 | 一系列食谱页面的链接，附带简短预览。 |
| **网页加载器引擎** | 打开其中一个链接并获取页面文本。 | 真正的食谱：配料和步骤。 |

**“网页加载器”其实就是“网页阅读器”。** 搜索结果通常包含一个链接和一段简短预览。当 AI 需要更多细节时，加载器会直接从页面本身获取文本。它也可以读取你粘贴到对话中的链接。

这正是存在两个设置的原因：一个决定**由谁查找链接**，另一个决定**如何读取这些链接背后的页面**。

即使关闭网页搜索，网页加载器的设置依然适用。**网页搜索引擎**只在开启 **网页搜索** 时才需要，因此**加载器**设置可以在没有引擎的情况下保存。当 **网页搜索** 关闭时，页面会隐藏 **网页搜索确认**、**网页搜索引擎**及其设置、**搜索限制**、**抓取 URL 内容长度上限**、**域名过滤列表** 和 **绕过网页加载器**。它们已保存的值会被保留。**绕过嵌入与检索** 和 **信任代理环境变量** 仍然可见。

## 为什么有这么多选项？ {#why-are-there-so-many-options}

Open WebUI 允许你为每项工作选择不同的服务。这些列表是**供你挑选的备选项**。你**不需要**把它们全部配置起来。

- **搜索引擎提供了不同的查找方式。** 有些无需账号，有些需要账号并可能对搜索收费，还有些可以在你自己的服务器上运行。它们对同一个问题也可能返回不同的结果。
- **网页加载器提供了不同的页面读取方式。** 网站的构建方式各不相同：有些直接提供文本，另一些则需要浏览器运行页面后文本才会出现。不同的加载器对这些情况的处理方式也不同。

某些服务（例如 Tavily 和 [Exa](/features/chat-conversations/web-search/providers/exa#4-optional-use-exa-to-read-pages)）可以同时完成这两项工作，因此你可能会在两个列表中看到相同的名称。你也可以为这两项工作分别使用不同的服务。

## 我该选择什么来开始？ {#what-should-i-choose-to-get-started}

:::tip 搜索引擎质量
若想要最强的搜索结果，可以从为 LLM 工作流打造的托管搜索 API 开始，例如 [Exa](/features/chat-conversations/web-search/providers/exa)、[Tavily](/features/chat-conversations/web-search/providers/tavily)、[SearchApi](/features/chat-conversations/web-search/providers/searchapi)、[Serper](/features/chat-conversations/web-search/providers/serper)、[SerpApi](/features/chat-conversations/web-search/providers/serpapi)、[Brave](/features/chat-conversations/web-search/providers/brave) 或 [Kagi](/features/chat-conversations/web-search/providers/kagi)。若你需要一个自托管、保护隐私的元搜索引擎，[SearXNG](/features/chat-conversations/web-search/providers/searxng) 仍然很有用，但其结果质量很大程度上取决于上游引擎、速率限制和实例配置。
:::

1. **选择一个搜索引擎，并按照下方的配置指南进行设置。** 托管搜索 API 是 Open WebUI 连接的服务，用于代替你执行搜索。这类服务通常需要账号和 **API key**：也就是一段用于把 Open WebUI 与你在该服务上的账号连接起来的代码。
2. **网页加载器保持默认设置即可。** 你不需要单独配置页面读取服务就能开始使用。如果页面无法被读取，[故障排查指南](/troubleshooting/web-search) 可以帮助你判断是否需要更换加载器。[加载器设置参考](/reference/env-configuration#web-loader-configuration) 会说明有哪些可选项。

:::tip 搜索正常，但页面内容是空的？
找到某个页面并不保证 Open WebUI 就能读取它。某个网站可能出现在搜索结果中，却阻止工具打开它，或者以你的加载器无法解析的方式加载文本。
:::

![网页搜索设置](/images/admin/admin-web-search.png)

:::tip 搜索前要求确认
管理员可以要求用户在**执行网页搜索前先确认**，以避免查询在无意中被发送到外部提供商。可在 **设置 → 网页搜索**（管理员区域） 中开启（当 **网页搜索** 处于开启状态时该开关才会显示，或通过 [`ENABLE_WEB_SEARCH_CONFIRMATION`](/reference/env-configuration#enable_web_search_confirmation) 开启）；提示文本由 [`WEB_SEARCH_CONFIRMATION_CONTENT`](/reference/env-configuration#web_search_confirmation_content) 设置。
:::

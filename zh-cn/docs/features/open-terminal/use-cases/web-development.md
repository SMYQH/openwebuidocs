# 构建和预览网站 {#build-and-preview-websites}

Open Terminal 最令人印象深刻的功能之一是：AI 会构建一个网站、启动服务器，您可以**在浏览器标签页中实时查看效果**，所有操作均在 Open WebUI 内完成。随后，您只需告知它需要修改的内容，并刷新页面即可查看结果。

---

## 工作原理 {#how-it-works}

1. 你要求 AI 创建一个网站（或 Web 应用、落地页，或任何基于 Web 的内容）
2. AI 创建文件并启动 Web 服务器
3. Open Terminal **自动检测**运行中的服务器
4. 您可从[浏览器标签页](#the-browser-tab)的**端口**列表中打开它
5. 您提出修改要求 → AI 编辑文件 → 您刷新页面

![AI 正在检查 8080 端口的状态页面是否响应，并对其进行总结](/images/open-terminal-ai-web-dev.png)

## "给我做一个落地页" {#make-me-a-landing-page}

> **你：** 为我的摄影业务创建一个落地页。包含一个作品集、一个关于部分和一个联系表单。

AI 会生成 HTML、CSS 和 JavaScript 文件，启动 Web 服务器，随后该页面便会显示在**端口**列表中。其外观专业且精致，绝非简单的线框图。

![文件浏览器显示已创建的 HTML 文件](/images/open-terminal-ai-web-dev-files.png)

## "更改颜色和布局" {#change-the-colors-and-layout}

页面上线后，只需继续对话即可迭代：

> **你：** 将背景设为深色，使用更温暖的配色方案。将作品集移到关于部分的上方。

AI 会编辑 CSS 和 HTML 文件。请重新加载浏览器标签页以查看更改。

## 端口检测的工作原理 {#how-port-detection-works}

无需进行任何特殊操作，服务器就会自动显示。幕后原理：

1. AI 启动一个 Web 服务器（如 `python -m http.server 3000` 或任何其他服务器）
2. Open Terminal 监控新的网络端口
3. 当检测到服务器正在运行时，它将端口报告给 Open WebUI
4. 浏览器标签页的**端口**列表中显示了这一点，而 Open WebUI 通过其自身的连接对流量进行代理

这意味着**你不需要打开额外端口**或更改任何防火墙设置。它开箱即用。

:::tip 多个服务器
如果 AI 启动了多个服务器（例如，端口 3000 上的前端和端口 5000 上的后端 API），每个服务器在**端口**列表中都会有一行。请在各自的浏览器标签页中打开它们。
:::

## 浏览器标签页 {#the-browser-tab}

在支持浏览器会话的终端上，**标签页**的 **+** 菜单会提供 **浏览器**。它的起始页会列出该终端正在提供的**端口**；点击其中一个即可加载，也可以直接输入任意 http 或 https 地址。

选项菜单（**...**）用于选择页面加载方式。**Chrome** 在终端上运行 Chrome，并将画面实时传到标签页，提供**移动视图**和画质设置。**代理**通过终端加载页面。终端支持时，新的浏览器标签页默认使用 Chrome，否则使用代理。如果 Chrome 出现故障，标签页会切换到代理并显示 **Chrome failed. Switched to Proxy.**。如果你或终端失去访问权限，正在运行的会话会结束。

## 桌面标签页 {#the-desktop-tab}

在支持该功能的终端上，**+** 菜单还提供 **Desktop**。它显示终端的桌面，可用鼠标和键盘操作，也支持粘贴。如果远程桌面没有自己的剪贴板，系统会将粘贴的文本逐字输入。点击相应按钮可打开全屏视图。如果终端提供桌面音频，点击扬声器按钮（**Unmute** / **Mute**）可播放或静音。

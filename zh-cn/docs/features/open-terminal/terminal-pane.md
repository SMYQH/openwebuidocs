# 终端面板 {#the-terminal-pane}

在[文件浏览器](./file-browser.md)下方，是一个实时展示 AI 正在运行什么的视图：AI 启动的每条命令都会获得一个独立的标签页。若要使用你自己的交互式 shell，可从**标签页**的 **+** 菜单中选择**新建终端**；你可以同时打开多个。

AI 运行过命令之后它才会出现，此时折叠为一条标有**会话**的窄条。有命令正在运行时，这条窄条上会显示数量。点击该窄条，或点击它右侧的折叠箭头，即可展开。

---

## 每条命令一个标签页 {#a-tab-per-command}

AI 运行的每条命令都会显示为独立的标签页，并以命令本身作为标签。标签前的小圆点表示状态：

| 圆点 | 含义 |
| :--- | :--- |
| 绿色 | 仍在运行 |
| 红色 | 已结束，退出码非零 |
| 灰色 | 正常结束，或终端已不再知道它的存在 |

把鼠标悬停在标签上会用文字说明同样的信息，包括退出码。选中某个标签即可实时查看该命令的输出。输出量超过面板保留上限的命令，其开头会有一行说明早先的输出已被省略。

已结束命令的标签上带有一个 **✕**，用于关闭该标签。正在运行的命令无法关闭，这是有意为之：这个标签是其输出的唯一展示位置。你关闭的标签会保持关闭状态，尽管终端仍然列出了该命令本身。

当焦点位于标签栏时，**方向键**可在标签之间移动，**Home** 与 **End** 则跳转到第一个和最后一个标签。

---

## 值得了解 {#good-to-know}

:::tip 面板只用于查看
关闭一个标签或折叠整个面板，都不会改变 AI 正在做的事。这些只是你观看终端的视角，而不是对它的控制。
:::

:::info 只有你正在看的那个标签会发送输出
命令列表是实时推送的；面板展开时，屏幕上那个标签的输出同样是实时推送的。处于后台标签中的命令，在你切换过去之前不会向你的浏览器发送任何输出。
:::

:::info 一次只能看一个终端
该面板会跟随聊天中所选的终端，与文件浏览器的行为一致。切换终端也就切换了你正在查看的机器。
:::

## 面向自托管的终端服务器 {#for-self-hosted-terminal-servers}

Open WebUI 通过 websocket 代理交互式终端，该连接会携带 `X-User-Id` 与 `X-Session-Id` 头，分别标明已登录用户和该终端所属的聊天，与 HTTP 代理的做法相同。按用户划分会话的终端服务器在两条路径上看到的身份是一致的。

Open WebUI 根据已认证的会话设置 `X-User-Id`，因此浏览器无法自行指定它。`X-Session-Id` 则是浏览器上报的聊天 ID。

# 律师事务所 Noerr 如何把为期八周的 Open WebUI 推广变成首周 600 多名活跃用户 {#how-law-firm-noerr-turned-an-eight-week-open-webui-rollout-into-600-active-users-in-week-one}

![Noerr](/images/enterprise/customers/noerr/hero.png)

## 概述 {#overview}

:::info
Noerr 在自己的 Azure 订阅内基于 Open WebUI 构建了 NoerrGPT——一个面向全所的安全 AI 工作区。它在加快法律工作节奏的同时，让数据、模型和合规性完全由自己掌控。
:::

### 概览 {#at-a-glance}

- **行业**：法律服务
- **公司规模**：1,000–4,999 名员工，其中超过 450 名顾问
- **部署方式**：Noerr 自己的 Azure 订阅，数据仅驻留在欧盟境内
- **模型**：Azure OpenAI GPT-6-Luna 与 GPT-6.1-Sol；AWS Anthropic Opus-5.5 与 Sonnet-5
- **部署周期**：从项目启动到全面推广共 8 周
- **使用情况**：首周活跃员工超过 600 人；前两周日活稳定在已授权席位的 60–70%
- **关键成果**：首周独立用户数即等同于原平台的月度独立用户数

## 关于 Noerr {#about-noerr}

[Noerr](https://www.noerr.com/) 是德国顶尖律师事务所之一，在六个国内办公室和四个国际办公室（包括伦敦和纽约）拥有超过 450 名顾问。该所业务覆盖公司与商法的广度与深度，为客户处理复杂的跨境事务。

为了保持优势，Noerr 正在投入负责任的 AI——在不让严格的客户保密与数据保护要求妥协的前提下，提升律师与支持人员的工作效率。

## 挑战：面向法律工作的现代 AI，且不妥协 {#the-challenge-modern-ai-for-legal-work-without-compromise}

在引入 Open WebUI 之前，Noerr 使用自建的内部 LLM 界面。随着 AI 创新节奏加快，该所有需求：

- 一个更简洁现代、让律师真正愿意使用的界面
- 更快地获取新能力和新模型
- 针对法律工作流的深度定制与集成选项
- 坚持仅在欧盟境内托管，并对数据、加密和日志拥有完全控制权的选项

现成的 SaaS 工具无法满足 Noerr 的标准：功能上线太慢、集成能力有限，而严格的内部数据保护政策也排除了把数据发送到外部厂商基础设施的做法。

## 解决方案：部署在 Noerr Azure 环境中的 NoerrGPT {#the-solution-noerrgpt-in-noerrs-azure-environment}

Noerr 选择 Open WebUI，是因为它能够完全部署在该所自己的 Azure 订阅内，同时保持高度可定制和快速迭代。

- **计算与编排**：Azure Kubernetes Service（AKS），并为 OCR 配置 GPU 节点自动扩缩容
- **存储与数据库**：Azure Database for PostgreSQL，静态加密并使用客户托管密钥
- **网络**：私有 VNet，以 LiteLLM 作为 LLM 请求的中枢
- **密钥管理**：Infisical
- **CI/CD**：Azure DevOps 流水线，使用 ArgoCD 进行部署
- **监控**：使用 Sentry 记录错误日志，使用 Gatus 进行可用性监控
- **沙箱终端**：在 AKS 上运行隔离的终端，用于智能体式的代码执行
- **安全控制**：MFA、设备合规检查、按群组划分的基于角色的访问、强制执行的欧盟数据驻留、内容审核与护栏、DLP 策略，以及向 SIEM 导出审计记录

## 模型、RAG 与数据保护 {#models-rag-and-data-protection}

Noerr 只在欧盟区域内运行托管于 Azure 和 AWS 的模型。用户可以自行选择模型，也可以依赖智能体式模型选择，由它根据提示词的目标挑选最合适的模型。

RAG 是专门为法律用例搭建的：使用混合搜索并配合 Azure 重排序模型，其知识来源也融合了内部内容与法律专有内容。

为保护高度机密的数据，内置 Web 搜索已在全局关闭。取而代之的是通过 Linkup 和 Noerr 自有来源运行的安全 Web 搜索。

## 推广与赋能 {#adoption-and-enablement}

在 8 周开发期结束时，Noerr 先邀请了 15 位数据与 AI 专家进行为期两周的定向 beta 测试，随后才向全所开放。NoerrGPT 向所有法律顾问以及包括人力资源、IT 和法律助理在内的支持部门开放。

赋能方式有意保持轻量且对律师友好：

- 针对内部使用场景编写的文档，以及
- 带现场演示的录播实操课程，用户可随时回看。

## 成果 {#results}

Noerr 强调了三项关键成果：

- **快速普及**：首周就有超过 600 名员工使用 NoerrGPT，这已相当于原平台的月度独立用户数，说明其吸引力与契合度都很高。前两周内，日活稳定在已授权席位的 60–70%。
- **高度认可**：尽管相较此前界面变化很大，律师和员工仍给出了积极反馈。
- **稳定性与性能**：Noerr 掌控范围内的所有服务都稳定高效，有力支撑了规模化下的日常法律工作。

## 主要使用场景 {#top-use-cases}

- 从核心业务系统与商业登记簿中以智能体方式检索数据
- 预置的提示词库，用于从合同和案卷中提取信息，以及起草、分析和修改条款
- 基于内部制度与指引的问答，由专门的机器人提供
- 确定性的数据处理与绘图
- 完全由智能体完成的技能选择与执行

## Noerr 为何选择 Open WebUI {#why-noerr-chose-open-webui}

- **开放架构**：不存在厂商锁定
- **速度**：快速的概念验证和 8 周的落地实施
- **完全掌控**：完全运行在 Noerr 的 Azure 环境中，采用自带密钥加密（BYOK）并完全拥有数据
- **灵活性**：足够灵活，可以添加自定义功能并对接内部工具

## 下一步 {#whats-next}

在安全且被广泛采用的 AI 工作区落地之后，Noerr 计划继续扩展使用场景、深化集成并打磨专属该所的工作流，同时保持客户所期待的高标准数据保护与合规水平。

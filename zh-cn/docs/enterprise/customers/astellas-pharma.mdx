## 关于 Astellas Pharma Inc. {#about-astellas-pharma-inc}

[Astellas Pharma Inc.](https://www.astellas.com/) 是一家全球生命科学公司，从事处方药的研发、销售、营销和制造。Astellas 在约 70 个国家开展业务，拥有近 20,000 名员工和承包商，致力于通过科学创新造福全球患者。

## 挑战：灵活、安全的 AI，无供应商锁定 {#the-challenge-flexible-secure-ai-without-vendor-lock-in}

随着生成式 AI 能力快速发展，Astellas 需要一个能够跟上步伐、不将组织绑定到单一模型提供商的平台。该公司在几十个国家运营，管理复杂的监管环境，并支持跨越多种语言和学科的科学工作流。第三方 SaaS 工具提供了有限的集成选项、受限的定制，且缺乏全球制药公司所需的安全和合规控制。

目标是：部署**安全的自托管 AI 平台**，使从 R&D 和临床开发到药物警戒和合规的每个部门都能灵活地利用尖端模型，同时保持对安全、合规和数据治理的完全控制。

**关键需求**

- **灵活的模型选择**：自由选择和切换提供商
- **使用本地托管模型的选项**：用于敏感分析
- **能够创建自定义模型**：针对特定工作流进行定制
- **安全共享和联合开发**：在指定群组内共享和共同开发模型
- **技术集成**：与内部和外部系统集成

## 解决方案：Azure 上的 Open WebUI {#the-solution-open-webui-on-azure}

选择 Open WebUI 是因为其**灵活性、细粒度权限控制和可扩展的架构**，允许 Astellas 在其安全的私有环境中完全托管，同时支持自定义模型创建和基于群组的协作。

**架构亮点**

- **计算/编排**：Kubernetes（AKS）集群，根据需求自动扩展
- **存储/数据库**：Azure Database for PostgreSQL（静态加密；备份符合内部政策）
- **网络**：VNet 隔离；应用网关配备私有端点用于 LLM API
- **机密**：Azure Key Vault 与 Open WebUI 集成，用于安全凭证管理
- **CI/CD**：Azure DevOps 管道用于升级、配置部署和治理控制
- **日志/监控**：API 管理服务、Azure 仪表板、Databricks
- **安全控制**：通过 IdP 的 MFA、基于群组的 RBAC、强制执行数据驻留

> "Open WebUI 允许我们在整个公司安全地创建和共享自定义 AI 模型，同时给我们灵活性来充分利用任何可用的尖端模型。" - Astellas 生成式 AI 团队经理

## 模型和数据处理 {#models--data-handling}

Astellas 采用**多模型、多提供商策略**，为每项任务提供合适的工具：

- **主要**：Azure OpenAI 模型
- **研究增强**：Gemini、DeepSeek、Perplexity（网络搜索增强）
- **模型选择**：高级用户可从所有可用模型中选择；新手用户则使用便于上手的精选选项。默认模型按用户群组分配，也可手动切换
- **RAG**：嵌入模型和分块大小针对性能优化。来源包括 SOP、监管政策文档和外部医学研究数据
- **敏感数据处理**：优先考虑数据治理。所有用户须先完成机密数据处理培训，才能获得访问权限。公司监控使用情况以确保合规，并通过运营流程按最小权限原则授予共享知识和模型的访问权限

## 推广与培训 {#adoption--enablement}

Astellas 为 **2,000+ 名员工开展了为期两个月的上手培训**，包括演示、互动研讨和实际操作。到推广阶段结束时，培训已覆盖全公司。

培训包括：

- **生成式 AI 基础**互动课程
- **Open WebUI 操作培训**，涵盖模型创建和共享
- 定期举办**答疑时段**，讨论进阶用法并解答问题

在接下来的几个月中：

- **周活跃用户在五个月内稳定在 30-40%**
- 用户自发创建了**数百个自定义模型**，在部门间共享
- **所有部门**都采用了该平台，包括研究、临床开发、医学、销售、市场营销、法律、合规、药物警戒、行政、通信和企业战略

> "我们在收集外部科学信息方面的效率大幅提高。能够根据使用情况选择和切换模型使我们的研究更加有效。" - Astellas 研究部门用户

R&D 和研究团队报告了在收集和综合科学信息、临床试验摘要和多语言医学文档方面的显著改进。

## 为什么 Astellas 选择 Open WebUI {#why-astellas-chose-open-webui}

- **模型自由**：选择、切换和更新模型，无供应商锁定
- **自定义模型创建**：员工构建和共享针对其工作流的模型
- **细粒度权限**：RBAC 和基于群组的协作控制
- **自托管灵活性**：在 Azure 内完全私有部署
- **深度集成**：连接到现有 Microsoft 生态系统和内部系统
- **可扩展架构**：从初始部署自发增长到 3,200+ 用户

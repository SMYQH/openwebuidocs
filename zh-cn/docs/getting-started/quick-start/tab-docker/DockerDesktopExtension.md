# Docker Desktop 扩展 {#docker-desktop-extension}
Docker 发布了一个 Open WebUI Docker 扩展，它使用 Docker Model Runner 进行推理。你可以在这篇入门博客中了解更多：[使用 Open WebUI + Docker Model Runner 在本地运行 AI](https://www.docker.com/blog/open-webui-docker-desktop-model-runner/)

该扩展的故障排查步骤可在其 GitHub 仓库中查看：[Open WebUI Docker 扩展 - 故障排查](https://github.com/rw4lll/open-webui-docker-extension?tab=readme-ov-file#troubleshooting)

这个扩展方便试用 Open WebUI，但不属于官方支持的安装方式，可能出现意外错误或行为。例如，该扩展面向单个本地用户，不能以不同用户身份登录。遇到问题时，请在扩展的 [GitHub 仓库](https://github.com/rw4lll/open-webui-docker-extension)提交问题。

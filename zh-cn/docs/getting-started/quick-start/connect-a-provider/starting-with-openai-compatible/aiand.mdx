[ai&](https://www.aiand.com/inference) 是 Open WebUI 的官方合作伙伴，通过在日本的自有基础设施为当地团队提供开放权重的 AI 模型。将 Open WebUI 的聊天与协作功能和 ai& 的托管推理相结合，无需运维 GPU 服务器就能为团队提供 AI 工作区。

## 为什么日本团队选择 ai&？ {#why-choose-ai-for-teams-in-japan}

- **让推理服务靠近用户。** ai& 在日本的自有基础设施上运行推理，旨在降低整个亚太地区的访问延迟。
- **让推理处理留在日本。** ai& 的[服务条款](https://www.aiand.com/legal/inference-terms-of-service)规定输入与输出在日本境内处理，并禁止使用这些内容训练模型。
- **选择适合工作的模型。** 通过一个 API 访问 Kimi、DeepSeek 和 GLM 等模型家族。在 Open WebUI 中比较模型，并从 [ai& 模型目录](https://docs.aiand.com/models/catalog/)中挑选适合编码、推理和日常团队聊天的模型。
- **从小处开始，再逐步扩大。** 先从按 token 计费开始，随着团队需求增长再探索预留算力和自定义 SLA。参见 [ai& 的套餐与价格](https://www.aiand.com/inference)。

**准备好把部署在日本的 AI 引入你的工作区了吗？** [创建一个 ai& API key](https://console.aiand.com/)，然后按下面的步骤操作。若需日文版概览，请访问 [ai& Inference 日本語](https://www.aiand.com/jp/inference)。

## 第 1 步：获取 API Key {#step-1-get-your-api-key}

1. 在 [console.aiand.com](https://console.aiand.com/) 登录。
2. 创建一个 API key 并妥善保存；该密钥只会显示一次。
3. 为你的账户充值，以便使用该 API。

有关账户与计费设置，请参阅 [ai& 快速入门](https://docs.aiand.com/getting-started/)。

## 第 2 步：在 Open WebUI 中添加连接 {#step-2-add-the-connection-in-open-webui}

1. 前往 **Settings > Connections**（管理员区域），找到 **Manage OpenAI API Connections** 列表。
2. 点击 **Add Connection**。
3. 填写以下设置：

| 设置项 | 值 |
|---|---|
| **URL** | `https://api.aiand.com/v1` |
| **API Key** | 你的 ai& API key |
| **Model IDs** | 留空以自动发现可用模型，或填写具体的模型 ID 来限定列表 |

4. 保持 **Advanced** 下的 **Provider** 为 **Default**。
5. 点击 **Verify Connection**，然后点击 **Save**。

ai& 提供了一个用于发现模型的 [`/v1/models` 端点](https://docs.aiand.com/api/models/)。把模型加入允许列表时，请使用该端点返回的准确模型 ID。

## 第 3 步：开始聊天 {#step-3-start-chatting}

打开一个新的聊天，从模型选择器中选中一个 ai& 模型，然后发送消息。

请选择具备你工作流所需能力的模型。可用模型、上下文窗口以及对推理、视觉、工具调用等功能的支持情况，请查阅 [ai& 模型目录](https://docs.aiand.com/models/catalog/)。

有关连接故障排查和其他配置选项，请参阅 [OpenAI 兼容指南](/getting-started/quick-start/connect-a-provider/starting-with-openai-compatible)。

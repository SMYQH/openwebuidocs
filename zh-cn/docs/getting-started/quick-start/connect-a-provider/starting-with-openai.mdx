## 概览 {#overview}

Open WebUI 可以轻松连接 **OpenAI** 和 **Azure OpenAI**。本指南介绍如何添加 API 密钥、填写正确的端点并选择模型，以便开始聊天。

对于其他提供兼容 OpenAI 的 API 的提供商（如 Mistral、Groq、DeepSeek 等），请参阅 **[兼容 OpenAI 的提供商](/getting-started/quick-start/connect-a-provider/starting-with-openai-compatible)** 指南。要使用 Anthropic 的 Claude 模型，请参阅 **[Anthropic（Claude）](/getting-started/quick-start/connect-a-provider/starting-with-anthropic)** 指南。

---

## 重要：我们支持的是协议，而不是厂商私有实现 {#important-protocols-not-providers}

Open WebUI 是一个**以协议为中心**的平台。虽然我们为 OpenAI 模型提供了一流支持，但本质上主要还是通过 **OpenAI 聊天补全 API 协议**来实现。

我们优先支持被几十家提供商共同采用的通用标准，并对 **[Open Responses](https://www.openresponses.org/)** 这类新兴标准提供实验性支持。关于这一设计思路的详细解释，请参见 **[协议支持 FAQ](/faq#q-why-doesnt-open-webui-natively-support-provider-xs-proprietary-api)**。

## 第 2 步：在 Open WebUI 中添加 API 连接 {#step-2-add-the-api-connection-in-open-webui}

当 Open WebUI 已经运行后：

1. 在管理员区域打开**设置 > 连接**。
2. 找到**管理 OpenAI API 连接**列表。
3. 点击旁边的**添加连接**。

<Tabs>
  <TabItem value="standard" label="OpenAI" default>

  *   **Connection Type**：External
  *   **URL**：`https://api.openai.com/v1`
  *   **API Key**：你的密钥（以 `sk-...` 开头）

  </TabItem>
  <TabItem value="azure" label="Azure OpenAI">

  适用于 Microsoft Azure OpenAI 部署。

  1. 展开**高级**，在**提供商**下拉列表中选择 **Azure OpenAI**。填写 Azure 端点 URL 后，通常会自动选择此项。
  2. **URL**：你的 Azure 端点（例如 `https://my-resource.openai.azure.com`）。
  3. **API Version**：例如 `2024-02-15-preview`。
  4. **API Key**：你的 Azure API Key。
  5. **Model IDs (Deployments)**：你**必须**在此填写具体的 Deployment Name（例如 `my-gpt4-deployment`）。

  </TabItem>
</Tabs>

### 高级配置 {#advanced-configuration}

*   **Model IDs**（位于 **Advanced** 下）：
    *   *默认（留空）*：自动检测提供商中的全部可用模型。
    *   *填写后*：将替换拉取到的列表。Open WebUI 不再为该连接调用提供商的 `/models`，而是只列出你输入的 ID，因此提供商报告的名称、大小和加载状态都不再有。可以用它隐藏较旧或昂贵的模型，或者为提供商并未列出的模型命名。
    *   *每个 ID 单独添加*：输入内容的前后空格会被去除；无法添加重复 ID，界面会提示 **Model ID is already added**。如果连接中已保存的列表含有重复 ID，重新打开连接时每个 ID 只会保留一项，保存时会写回去重后的列表。
*   **Prefix ID**：
    *   如果你连接了多个提供商，而它们存在同名模型（例如两个提供商都提供 `qwen3.6`），可在这里加上前缀（如 `groq`）以作区分。Open WebUI 会用点号把前缀和模型 ID 连接起来，模型显示为 `groq.qwen3.6`，并在请求发往上游之前再次去掉前缀。写成 `groq/` 的前缀会得到 `groq/.qwen3.6`。不加前缀时，Open WebUI 每个 ID 只保留一个模型：当两个连接返回相同 ID 时，它只列出列表中位置靠前的那个连接所提供的副本，并在不给出警告的情况下丢弃另一个。

*   **Provider**：
    *   告诉 Open WebUI 该 URL 对应的服务器类型，以启用 Azure 路由、本地模型管理或 Anthropic 请求透传等功能。使用 OpenAI 时请保留 **Default**。参见[提供商设置](/getting-started/quick-start/connect-a-provider/starting-with-openai-compatible#the-provider-setting)。

4. 点击 **Save**。

这样你的凭据就会被安全保存。

:::tip 连接超时配置

如果你的 API 提供商响应较慢，或你遇到了超时问题，可以调整模型列表获取超时：

```bash
# Increase timeout for slow networks (default is 10 seconds)
AIOHTTP_CLIENT_TIMEOUT_MODEL_LIST=15
```

如果你保存了一个不可达 URL，导致界面卡住，请参见 [模型列表加载问题](/troubleshooting/connection-error#model-list-loading-issues-slow-ui--unreachable-endpoints) 故障排查页面。

:::

## 第 3 步：开始使用模型 {#step-3-start-using-models}

保存连接后，你就可以直接在 Open WebUI 内使用模型。

🧠 无需下载任何模型——只要在模型选择器中选择一个模型并开始聊天即可。只要提供商支持该模型，你就能通过其 API 立即使用它。

模型选择界面如下：

![OpenAI 模型选择器](/images/getting-started/quick-start/selector-openai.png)

只需选择 GPT-5.6 Sol、GPT-5.6 Terra，或提供商提供的任意兼容模型即可。

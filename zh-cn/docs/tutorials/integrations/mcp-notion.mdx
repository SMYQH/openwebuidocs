Notion 在 `https://mcp.notion.com/mcp` 托管了一个远程 MCP 服务器，Open WebUI 通过 **Streamable HTTP** 原生连接。身份验证通过 Notion 的 OAuth 流程处理——无需 API 令牌、无需代理、无需额外容器。


## 设置 {#setup}

:::danger 前置条件：WEBUI_SECRET_KEY
您**必须**将 `WEBUI_SECRET_KEY` 环境变量设置为持久值。若不设置，每次容器重启后 OAuth 会话将中断，强制重新进行身份验证。详情请参见 [MCP 功能文档](/features/extensibility/mcp)。
:::

### 1. 添加工具 {#1-add-the-tool}

在管理员区域打开 **Settings > Integrations**，点击 **+** 添加新连接。填写以下信息：

| 字段 | 值 |
|-------|----|
| **Type** | MCP Streamable HTTP |
| **URL** | `https://mcp.notion.com/mcp` |
| **Auth** | OAuth 2.1 |
| **Name** | `Notion` |
| **Connection ID** | `ntn`（默认根据名称填充，请改为与下方导入配置一致的值） |

点击 **Register Client**，然后 **Save**。如果您已预先创建 OAuth 客户端凭据，请使用 `OAuth 2.1 (Static)`。您在 Notion 的 OAuth 客户端随后需要把重定向 URI 设置为 `<WebUI URL>/oauth/clients/mcp:ntn/callback`，参见 [OAuth 2.1 (Static) 设置](/features/extensibility/mcp#oauth-21-static-setup)。

<details>
<summary>备选方案：导入 JSON</summary>

您也可以把这份配置保存为 `.json` 文件，然后用弹窗中的 **Import** 加载它，该按钮会打开文件选择器；之后仍然需要点击 Register Client 和 Save：

```json
[
  {
    "type": "mcp",
    "url": "https://mcp.notion.com/mcp",
    "spec_type": "url",
    "spec": "",
    "path": "openapi.json",
    "auth_type": "oauth_2.1",
    "key": "",
    "info": {
      "id": "ntn",
      "name": "Notion",
      "description": "Search, read, create, and manage Notion pages and databases."
    }
  }
]
```

</details>

![已导入 Notion MCP 配置的外部工具弹窗。](/images/mcp-notion/notion-setup-step5.png)

### 2. 授权 {#2-authorize}

在任意聊天中打开 **+ > Tools** 并启用 **Notion**。进入 Notion 的 OAuth 流程后，选择工作区并授予访问权限。

![已开启 Notion 工具的聊天输入栏。](/images/mcp-notion/notion-setup-step6.png)

![Notion OAuth 授权界面。](/images/mcp-notion/notion-setup-step7.png)

:::warning OAuth 2.1 工具无法预先启用
**请勿**将此工具设置为模型的默认工具。OAuth 2.1 需要交互式浏览器重定向，无法在请求过程中进行。用户必须通过 **+** 按钮在每次聊天时手动启用。详情请参见 [MCP 文档](/features/extensibility/mcp)。
:::

:::note 重新验证
Notion 的 OAuth 会话可能因长时间未操作或容器重启而过期。如果出现 `Failed to connect to MCP server 'ntn'`，请在任意聊天中重新启用工具，启动授权流程。
:::


## 速率限制 {#rate-limits}

标准 [Notion API 限制](https://developers.notion.com/reference/request-limits)适用：

- **常规：** 每分钟 180 次请求
- **搜索：** 每分钟 30 次请求

## 故障排除 {#troubleshooting}

### `Failed to connect to MCP server 'ntn'` {#failed-to-connect-to-mcp-server-ntn}

OAuth 会话已过期。在任意聊天中重新启用 Notion 工具（**+ > Tools**）以重新授权。

![聊天中 MCP 服务器连接失败错误。](/images/mcp-notion/notion-setup-step12.png)

### `OAuth callback failed: OAuth callback state is invalid or expired` {#oauth-callback-failed-oauth-callback-state-is-invalid-or-expired}

如果通过 `localhost` 访问 Open WebUI，但 `WEBUI_URL` 配置的是公共域名，Notion 会将你重定向到另一个地址，那里没有你发起授权时的状态。请使用 `WEBUI_URL` 中的**确切 URL** 访问实例并重新授权。

如果中途退出登录，或者在一个浏览器开始授权、又在另一个浏览器完成授权，也会出现同样的错误。请重新登录，再在当前浏览器中重新启用该工具。

![从 Notion 返回后显示的 OAuth 回调状态错误。](/images/mcp-notion/notion-setup-step13.png)

### `Object not found` {#object-not-found}

该页面尚未与集成共享。在 OAuth 流程中，Notion 会询问授权访问哪些页面——请确保选择了相关页面。您可以随时通过 [Notion 集成设置](https://www.notion.so/profile/integrations)更新访问权限。

### 创建页面时出现 `missing_property` {#missing\_property-when-creating-a-page}

Notion 需要父页面或数据库。请告诉模型：*“先搜索我的‘Notes’页面，然后在其中创建新页面。”*

# 在离线模式下运行 Open WebUI {#running-open-webui-in-offline-mode}

要在没有互联网连接的情况下使用 Open WebUI，请先准备好本地的推理、嵌入和文档提取服务，然后再断开连接。把界面运行在本地，并不会让这些服务也变成本地的。离线设置可以阻止部分下载和更新检查；而要阻止外部网络访问，则需要另外的网络控制手段。

:::warning

本教程由社区贡献，不属于 Open WebUI 团队的官方支持范围。它仅用于演示如何针对你的具体使用场景定制 Open WebUI。想参与贡献？请查看[贡献教程](/contributing)。

:::

## 本地必须具备哪些条件 {#what-does-offline-mode-mean}

请确认 Open WebUI 已正常运行，且你拥有管理员权限。断开互联网连接前，主机、容器和依赖的服务都必须准备好所需文件和依赖项：

- **对话：** 一个本地推理服务器和已下载的模型。按照现有的 [Ollama 连接指南](/getting-started/quick-start/connect-a-provider/starting-with-ollama)操作，然后选择一个本地模型，而不是 Ollama 云模型或其他托管端点。
- **文档检索：** 一个已下载的嵌入模型或可达的本地嵌入服务、本地文档提取，以及在启用重排序时的本地重排器。请检查 **设置 → 文档**（管理员区域）中选定的提供方；仅仅有一个本地对话模型，并不能让文档处理也留在本地。
- **安装与存储：** Open WebUI 镜像或软件包、所需依赖以及持久化的模型缓存。任何可选的提取服务或工具服务同样需要它自己的安装文件和依赖。
- **登录：** 在隔离网络中仍然可达的认证方式。请在移除对外部身份提供方的访问之前先测试它。
- **语音（如果需要）：** 本地语音模型、音色及其依赖。语音功能对于对话和文档检索来说是可选的。

云端模型、托管的网页搜索、外部认证以及其他互联网服务，在网络访问被移除后可能无法工作。有关已配置的服务如何影响数据流向，请参阅[聊天数据隐私与加密](/security/chat-data-privacy-and-encryption)。

## 在仍联网时进行准备 {#approach-ii}

### 下载并测试依赖 {#running-open-webui-with-internet-connection-during-setup}

如果这台机器在准备阶段还能连接互联网，请准备好你离线运行时会使用的同一套安装：

1. 安装 Open WebUI，并按照 [Ollama 指南](/getting-started/quick-start/connect-a-provider/starting-with-ollama)连接一个本地推理服务器。下载你打算使用的模型，并发送一条测试消息。
2. 配置本地文档提取与嵌入。下载并试用你需要的可选重排序模型或语音模型。
3. 把应用数据和模型缓存放在持久化存储中。在仍处于联网状态时重启一次，确认安装确实使用了该存储。

### 准备嵌入模型 {#ii-embedding-model}

在**设置 → 文档**（管理员区域）中选择你的本地嵌入模型，例如 [sentence-transformers/all-MiniLM-L6-v2](https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2)，并使用下载按钮。如果你使用独立的本地嵌入服务，请准备好它的模型并确认 Open WebUI 可以访问它。

上传一份较小的文本型 PDF 或文本文件，等待处理完成，再提出一个答案可在文件中找到的问题。完整流程请参阅[文档问答快速入门](/features/workspace/knowledge#ask-your-first-document-question)。普通对话成功并不代表文档处理已经就绪。

## 准备一台已经处于离线的机器 {#approach-i}

请使用一台联网的暂存机，为目标机器的操作系统和硬件下载应用程序镜像或软件包、模型文件以及依赖，并通过你认可的流程传输它们。请保持模型缓存的目录结构完整，包括其中的符号链接及其指向的目标，并确保 Open WebUI 进程能够读取传输过来的文件。

按照 [Ollama 指南](/getting-started/quick-start/connect-a-provider/starting-with-ollama)准备推理服务器及其模型。对于 Open WebUI 的本地处理模型，下面的示例会在联网的暂存机上下载缓存。文中给出的目标路径是 Docker 安装的默认值；如果你使用其他数据目录，请相应调整。

### 可选的语音转文字 {#i-speech-to-text}

本地 Whisper 需要已下载的模型文件。在联网的机器上安装 `huggingface_hub` 后，下载所选的 faster-whisper 模型：

```python
from huggingface_hub import snapshot_download

snapshot_download(
    repo_id="Systran/faster-whisper-large-v3",
    cache_dir="/path/to/whisper-cache",
)
```

把该缓存目录的内容复制到目标部署中的 `/app/backend/data/cache/whisper/models/`，并保持其目录结构。配置 `WHISPER_MODEL=Systran/faster-whisper-large-v3`，或选择更小的模型并使用与之匹配的标识符。自定义缓存位置请参阅[语音转文字配置](/features/chat-conversations/audio/speech-to-text/stt-config)和 [`WHISPER_MODEL_DIR`](/reference/env-configuration#whisper_model_dir)。

### 可选的文字转语音 {#i-text-to-speech}

如果你需要语音输出，请准备一个本地服务，例如 [Openedai-speech](/features/chat-conversations/audio/text-to-speech/openedai-speech-integration)，包括它的音色、模型文件和依赖。确认它在运行时不会下载任何内容即可正常工作。浏览器是否支持语音取决于浏览器和已安装的音色；请在你将离线使用的客户端设备上测试它。

### 嵌入模型 {#i-embedding-model}

若要使用 Open WebUI 的本地嵌入引擎进行文档检索，请在联网的机器上下载所选模型：

```python
from huggingface_hub import snapshot_download

snapshot_download(
    repo_id="sentence-transformers/all-MiniLM-L6-v2",
    cache_dir="/path/to/embedding-cache",
)
```

把该缓存目录的内容复制到目标部署中的 `/app/backend/data/cache/embedding/models/`，并保持其目录结构。把 [`RAG_EMBEDDING_MODEL`](/reference/env-configuration#rag_embedding_model) 设为与之匹配的模型标识符。如果你使用独立的本地嵌入服务，请改为按照该服务的说明准备它的模型缓存。你启用了重排序或提取模型时，请按相应服务的缓存要求以同样的方式准备它们。

## 启用离线设置 {#how-to-enable-offline-mode}

准备好模型和依赖之后，通过你的部署所采用的环境配置设置以下变量，并重启 Open WebUI：

```bash
OFFLINE_MODE=true
HF_HUB_OFFLINE=1
RAG_EMBEDDING_MODEL_AUTO_UPDATE=false
RAG_RERANKING_MODEL_AUTO_UPDATE=false
WHISPER_MODEL_AUTO_UPDATE=false
```

单独设置 `OFFLINE_MODE=true` 就会把 `HF_HUB_OFFLINE` 置为 `1`、禁用版本检查，并把三个 `*_AUTO_UPDATE` 标志全部强制为 false，因此另外四行是冗余的，但无害；`ENABLE_VERSION_UPDATE_CHECK=false` 是单独控制版本检查的开关。`WHISPER_MODEL_AUTO_UPDATE=false` 本身并不能阻止下载：如果缓存中缺少 Whisper 模型，Open WebUI 会在允许下载的情况下重试，只有 `HF_HUB_OFFLINE=1` 才能阻止这次尝试，这也是必须先准备好缓存的原因。完整行为请参阅[离线配置参考](/reference/env-configuration#offline_mode)。

:::warning 请在启用离线设置之前准备好缓存

设置 `HF_HUB_OFFLINE=1` 后，缺失的模型就无法再下载。全新安装可能能够正常启动，但在第一次上传或查询文档时失败。如果看到 **No embedding model is loaded**，请查阅[离线嵌入排错步骤](/troubleshooting/startup#valueerror-no-embedding-model-is-loaded-with-offline-mode-on-a-fresh-install)。

:::

这些变量不会阻止对外发出的连接。外部模型 API、OAuth 提供商、网页搜索、工具以及其他已配置的服务，在网络允许的情况下仍然可以发起网络请求。

## 限制外部网络访问 {#sidenote}

请根据部署情况，采用合适的防火墙规则、容器网络或物理网络隔离来阻止外部访问。同时要保持必要的本地网络连接：浏览器必须能够访问 Open WebUI，Open WebUI 也必须能够访问本地推理和处理服务。

下面的 Docker Compose 片段是**内部容器网络的一个示例**，而不是一份完整的部署方案。它假定镜像已经存在、模型缓存目录中已包含准备好的缓存，并且你会提供一个连接到该网络的反向代理。你的本地模型服务器以及任何提取或嵌入服务也必须能从该网络访问；一个被隔离的 Open WebUI 容器无法使用位于无关网络上的模型服务器。在依赖这个示例实现隔离之前，请先调整并测试连通性。

```yaml
services:
  # Requires a reverse proxy and reachable local model/processing services.
  open-webui:
    image: ghcr.io/open-webui/open-webui:main
    restart: unless-stopped
    environment:
      - OFFLINE_MODE=true
      - HF_HUB_OFFLINE=1
      - RAG_EMBEDDING_MODEL_AUTO_UPDATE=false
      - RAG_RERANKING_MODEL_AUTO_UPDATE=false
      - WHISPER_MODEL_AUTO_UPDATE=false
      - RAG_EMBEDDING_MODEL=sentence-transformers/all-MiniLM-L6-v2
      # Optional: only needed when using local speech-to-text.
      - WHISPER_MODEL=Systran/faster-whisper-large-v3
    volumes:
      - ./open-webui-data:/app/backend/data
      - ./models/embedding-cache:/app/backend/data/cache/embedding/models/
      # Optional: prepared Whisper cache.
      - ./models/whisper-cache:/app/backend/data/cache/whisper/models/
    networks:
      - open-webui-internal

networks:
  open-webui-internal:
    name: open-webui-internal-network
    driver: bridge
    internal: true
```

## 验证对话与文档检索 {#verify-chat-and-document-retrieval}

在互联网访问被阻断、而必需的本地服务仍然可达的情况下：

1. **重启 Open WebUI 及其本地服务。** 检查日志中是否有缺失的依赖或尝试下载的记录，然后使用你打算在离线时使用的认证方式登录。
2. **发送一条普通的聊天消息。** 选择你的本地模型，确认重启后它仍能响应。
3. **上传一份新的小文档。** 使用包含易于识别的事实的文本文件或文本型 PDF，例如“测试办公室于 09:15 开门”。等待处理完成。
4. **询问该事实。** 附加该文件或知识库，询问测试办公室何时开门，并把答案与文档内容进行比对。附加步骤和前提条件请参阅[知识库](/features/workspace/knowledge#ask-your-first-document-question)。
5. **单独检查网络控制。** 通过防火墙或网络监控确认外部访问已被阻断。聊天和检索成功只能证明这些工作流在离线状态下可用，本身并不能证明网络是隔离的。

如果对话正常但文档测试失败，请检查所选的提取和嵌入提供方、缓存权限，以及[文档检索排错指南](/troubleshooting/rag)。如果你启用了语音，请单独测试它。

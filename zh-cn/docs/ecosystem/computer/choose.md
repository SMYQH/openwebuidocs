# Computer、Open WebUI 还是 Open Terminal？ {#computer-open-webui-or-open-terminal}

:::info 推荐配置
Open WebUI Computer 正在逐步弃用。对于新的部署，请使用 [Open WebUI](/getting-started) 搭配 [Open Terminal](/features/open-terminal)。这些 Computer 指南仍会为现有安装保留。
:::

**推荐使用 Open WebUI 搭配 Open Terminal。** Open WebUI 提供模型、对话、知识库、用户和权限；Open Terminal 补上文件、shell 命令、代码执行、运行中的进程和预览，让 Agent 可以在对话中完成工作。

- [开始使用 Open WebUI](/getting-started)。
- [安装 Open Terminal](/features/open-terminal/setup/installation)并[将它连接到 Open WebUI](/features/open-terminal/setup/connecting)。
- 如需托管的、按用户划分的工作区，请参见[终端](/features/open-terminal/terminals/)。
- 若要通过 Open WebUI 使用编码 Agent，请参见[编码 Agent](/features/open-terminal/coding-agents)。

## 现有的 Computer 安装 {#existing-computer-installations}

Computer 通过浏览器提供对机器文件、编辑器、终端、git 和 AI 工具的访问。现有用户可以查阅[网关集成](/ecosystem/computer/automate/open-webui)、[数据与备份](/ecosystem/computer/operate/data-and-backups)和[安全模型](/ecosystem/computer/phone-and-remote/security)。

Open WebUI 搭配 Open Terminal 是另一套独立的部署方案。改动已有安装之前，请先备份你的 Computer 数据。

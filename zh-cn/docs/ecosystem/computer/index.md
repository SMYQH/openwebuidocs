Open WebUI Computer（`cptr`）让你通过浏览器访问机器上的文件、编辑器、终端、git 和 AI 工具。

## 推荐路径 {#recommended-path}

Agent 工作流请使用 **Open WebUI 搭配 Open Terminal**。Open WebUI 提供聊天界面、模型、知识库和访问控制；Open Terminal 增加了用于文件、shell 命令、代码执行和预览的工作区。

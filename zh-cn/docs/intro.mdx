# Open WebUI

**Open WebUI 是一个 AI 的家**——一个自托管的 AI 平台，**[可扩展](https://docs.openwebui.com/features/extensibility/plugin/)**、**[功能丰富](https://docs.openwebui.com/features/)**、易于使用，并且被设计为能够**[完全离线运行](https://openwebui.com/sovereign-ai)**。它支持 **Ollama** 和**兼容 OpenAI 的 API**，无论是本地模型还是云端模型，都能为你提供一套强大且与提供商无关的界面。

## 快速开始 {#quick-start}

<Tabs>
  <TabItem value="python" label="Python" default>

```bash
# 已安装 uv（macOS/Linux）
DATA_DIR=~/.open-webui uvx --python 3.12 open-webui@latest serve

# 或者用 pip 安装并运行
pip install open-webui
open-webui serve
```

然后打开 [http://localhost:8080](http://localhost:8080)。

  </TabItem>
  <TabItem value="docker" label="Docker">

:::tip 选对镜像
使用 `:main` 以获得内置的嵌入、文档提取和语音识别。若追求**精简、内存高效、可扩展**的部署，请选择 `:slim`：**下载体积 197 MB**（小 88%），在我们的[测试](/getting-started/quick-start#slim-memory-usage)中**空闲时仅占约 300 MiB 内存**。你将获得完全相同的聊天体验，**开销极小**、**占用极低**，嵌入、文档提取和语音则交由外部服务处理。[为什么选择 slim？](/getting-started/quick-start#what-slim-leaves-out)
:::

```bash
docker run -d -p 3000:8080 --add-host=host.docker.internal:host-gateway -v open-webui:/app/backend/data -e WEBUI_SECRET_KEY=your-secret-key --name open-webui --restart always ghcr.io/open-webui/open-webui:main
```

如需 GPU 支持、Docker Compose 等更多内容 → [快速开始](/getting-started/quick-start) 和 [Docker 镜像与标签](/getting-started/quick-start#image-variants)

然后打开 [http://localhost:3000](http://localhost:3000)。

  </TabItem>
  <TabItem value="desktop" label="桌面端">

:::info
用于生产环境时，请通过 **Docker** 或 **Python** 安装。
:::

从 [**github.com/open-webui/desktop**](https://github.com/open-webui/desktop) 下载桌面应用。它可在你的系统上原生运行 Open WebUI，无需 Docker 或手动配置。

  </TabItem>
</Tabs>

## 用 Open Terminal 实现代理式执行 {#agentic-execution-with-open-terminal}

[**Open Terminal**](/features/open-terminal) 让代理获得真正的终端和文件系统，因此它能真正完成多步工作，而不只是描述这些工作：分析数据、运行脚本、修复自己的错误，并把它生成的文件交给你——全部在聊天内完成。对话旁边的[文件浏览器](/features/open-terminal/file-browser)会展示它创建的一切。

对于团队，[**Terminals**](/features/open-terminal/terminals) 是其上的企业层，为每位用户提供隔离的环境，并配有资源限制和自动生命周期管理。

## 其他 Open WebUI 项目 {#also-by-open-webui}

- [**open-terminal**](https://github.com/open-webui/open-terminal) — 把 Open WebUI 变成完整的代理框架，配上真实的行动运行时：沙箱化的文件、shell、代码执行、预览和产物。
- [**oikb**](https://github.com/open-webui/oikb) — 让你的 Open WebUI 知识库保持同步。可监控本地文件夹、GitHub 仓库、S3 存储桶、Confluence 以及其他 40+ 种数据源。
- [**mcpo**](https://github.com/open-webui/mcpo) — MCP 转 OpenAPI 代理。在 Open WebUI（或任何 OpenAPI 客户端）中使用任意 MCP 工具服务器，无需自写胶水代码。

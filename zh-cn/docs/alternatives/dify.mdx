# Open WebUI 与 Dify {#open-webui--dify}

*最后更新：2026 年 8 月*

[Dify](https://dify.ai/) 由 LangGenius 开发，采用了不同的思路。这里介绍的许多工具侧重对话，Dify 则专注于*构建*：设计可视化工作流、编排智能体、调试提示词，以及部署由 AI 驱动的应用。如果你想用 AI 构建产品、自动化流程和面向用户的功能，Dify 值得考虑。

[GitHub](https://github.com/langgenius/dify) · [源代码可用（修改版 Apache 2.0 许可证）](https://github.com/langgenius/dify/blob/main/LICENSE)

---

## Dify 擅长的领域 {#what-dify-does-well}

- **可视化工作流构建器**，具有拖放界面，用于设计复杂的 AI 管道和逻辑
- **智能体框架**，用于构建能够推理、使用工具和采取行动的自主智能体
- **提示工程 IDE**，用于在专用环境中制作、版本控制、测试和比较提示
- **工作流市场**，用于共享和导入社区构建的工作流和模板
- **模型路由**，具有跨多个提供商的智能路由，用于成本和功能优化
- **RAG 管道**，包含内置的文档摄取、处理和检索
- **批处理**，用于针对大型数据集运行提示和工作流
- **注释和反馈**，用于收集人工反馈以随时间改进 AI 输出
- **可观测性**，包括生产使用的集成监控、日志记录和成本跟踪
- **后端即服务**，用于即时将 AI 应用作为 API 部署
- **可嵌入的小部件**，用于将 AI 聊天添加到任何网站或应用
- **强大的社区**，拥有大量活跃的贡献者和用户基础

---

## Open WebUI 擅长的领域 {#what-open-webui-does-well}

- **完整的 Agentic 平台**：在以对话为优先的工作区中，模型通过[内置工具](/features/extensibility/plugin/tools#built-in-system-tools-nativeagentic-mode)、[MCP](/features/extensibility/mcp) 服务器、[子智能体](/features/chat-conversations/chat-features/subagents)、[计时器](/features/chat-conversations/chat-features/timers) 和[自动化](/features/chat-conversations/chat-features/automations)开展工作
- **几乎一切都可以定制**：从按模型的提示词、工具、知识库和参数，到可以改变管道任意环节行为的[过滤器、管道、动作和事件函数](/features/extensibility/plugin/functions)，再加上主题、横幅和按群组的权限
- **任何模型、任何提供商**：同一个界面中包含 Ollama、OpenAI、Anthropic、Google、Azure 和 Bedrock
- **知识库与 RAG**：13 个向量数据库、8 个提取引擎，以及带重排序的混合搜索
- **团队协作**：包含频道、模型代理、RBAC、SSO/OIDC/LDAP 和 SCIM 2.0
- **Open Terminal**：提供用于代码执行的完整沙箱计算环境
- **更简单的部署**：单个 Docker 容器即可开始

## 如何选择 {#when-to-use-each}

**选择 Dify**：如果你想用可视化工作流构建由 AI 驱动的应用。拖放构建器、提示词 IDE 和智能体框架适合开发人员和产品团队构建 AI 功能。

**选择 Open WebUI**：如果你的团队需要一个日常聊天、管理知识和协作的 AI 工作区。Open WebUI 侧重使用 AI，而不是构建 AI 应用。

**搭配使用**。通过适配器将 Dify 的应用 API 封装为 OpenAI 兼容服务，就能在 Dify 中构建工作流，并在 Open WebUI 中以模型的形式使用。

## 搭配使用 {#use-them-together}

Dify 发布的应用有自己的[应用 API](https://docs.dify.ai/en/api-reference/guides/get-started)，请求和响应格式不同于 OpenAI。Open WebUI 不能直接将它作为 OpenAI 连接使用。通过兼容适配器，可以将 Dify 的工作流编排与 Open WebUI 的聊天、知识管理和团队功能结合起来。

**如何连接：**

1. 在 Dify 中发布应用，获取应用的 API 端点和密钥。
2. 配置适配器。让它接收 OpenAI Chat Completions 请求，并按 Dify 应用所需的格式转发请求和转换响应。
3. 在 Open WebUI 管理员区域的**设置 → 连接**中添加 OpenAI 兼容连接，填写适配器的 URL 和连接凭据。
4. 选择适配器为该应用提供的模型。如果适配器不返回模型列表，请在连接中手动填写模型 ID。

## 常见问题 {#frequently-asked-questions}

**Dify 和 Open WebUI 有什么区别？**
Dify 以可视化工作流为核心，适合构建 AI 应用。Open WebUI 更侧重对话和日常使用。两者侧重点不同，团队可以搭配使用。

**可以同时使用 Dify 和 Open WebUI 吗？**
可以，但不能将 Dify 原生应用 API 直接添加为 OpenAI 连接。需要先用适配器将 Dify 应用封装为 OpenAI 兼容服务。

**Dify 免费吗？**
社区版可免费自托管。Dify 以修改版 Apache 2.0 许可证提供源代码。

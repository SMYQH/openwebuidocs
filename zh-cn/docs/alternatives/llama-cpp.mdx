# Open WebUI 与 llama.cpp {#open-webui--llamacpp}

*最后更新：2026 年 11 月 14 日*

[llama.cpp](https://github.com/ggml-org/llama.cpp) 由 Georgi Gerganov 发起，让在日常硬件上运行强大模型变得触手可及，并惠及整个生态。我们非常欣赏这份工作，而 **[Llama app](https://llama.app/)** 让它更好用：这是来自 llama.cpp 团队和 Hugging Face 的官方桌面应用，提供模型下载、浏览器聊天，以及可供你其他应用使用的本地 API。

[Llama app](https://llama.app/) · [文档](https://llama.app/docs) · [GitHub](https://github.com/ggml-org/llama.cpp) · [MIT 许可证](https://github.com/ggml-org/llama.cpp/blob/master/LICENSE)

## Llama app：几步就能用上本地 AI {#llama-app-local-ai-in-a-few-clicks}

Llama 常驻在 **Mac 菜单栏**或 **Windows 11 系统托盘**。安装它、选择并下载推荐的模型，然后打开聊天界面。该应用还会安装 `llama` 命令供终端使用。在 Linux 上，CLI 和浏览器界面是主要入口。参见[官方安装指南](https://llama.app/docs/installation)。

应用会针对你的硬件推荐模型并处理其设置。模型与 llama.cpp 共用 Hugging Face 缓存，按需加载，空闲时卸载。你可以在本地聊天，也可以让编辑器、编码智能体和其他客户端使用同一个 API。对于希望几乎零配置就获得本地 AI 的人来说，这是一个很有吸引力的独立选项。[探索 Llama app →](https://llama.app/)

### llama.cpp 的新变化 {#whats-new-in-llamacpp}

团队在 **2026 年 11 月 13 日发布了 v1.0.0**，并承诺通过提升主版本号来标明公共库 API 和 ABI 的破坏性变更。对众多基于 llama.cpp 构建的项目来说，这是一个值得记住的里程碑。[阅读公告 →](https://huggingface.co/blog/ggml-org/llama-cpp-v1)

这次发布还带来了**聊天分组、重新设计的浏览器界面、实时预览的 Markdown 编辑器以及移动端布局改进**，同时还有 FP8 KV 缓存、在主机内存中缓存混合专家模型的改进，以及面向受支持模型的兼容 OpenAI 语音生成端点。[查看 v1.0.0 发布说明 →](https://github.com/ggml-org/llama.cpp/releases/tag/v1.0.0)

## llama.cpp 擅长的领域 {#what-llamacpp-does-well}

- **官方桌面应用**，用于在 Mac 和 Windows 上管理本地模型并与之聊天
- **内置浏览器聊天**，支持会话分支、搜索、JSON 导入导出、推理展示和 MCP。图片、PDF 和音频附件在兼容模型上可用。[Web 界面文档](https://llama.app/docs/webui)
- **广泛的硬件支持**，包括 CPU、CUDA、Metal、Vulkan 和 SYCL
- **GGUF 模型生态**，Hugging Face 上有开箱即用的量化模型
- **量化选项**，从 Q2 到 Q8，多种策略实现不同的质量/速度权衡
- **推测解码**，使用草稿模型加速生成
- **Flash Attention** 和其他先进推理优化
- **语法约束生成**，用于结构化输出（JSON、代码等）
- **兼容 OpenAI 和 Anthropic 的 API**，包括流式输出、工具调用和结构化输出，便于接入其他应用。[API 文档](https://llama.app/docs/api)
- **多模型路由模式**，按需加载，并支持并发请求和连续批处理。[服务器文档](https://llama.app/docs/serve)
- **MIT 许可证**，维护活跃

## Open WebUI 擅长的领域 {#what-open-webui-does-well}

Llama 已提供聊天界面和工具支持。Open WebUI 在此基础上提供共享工作区，支持知识管理、管理设置、自定义和接入多个提供商：

- **完整的 Agentic 平台**：运行在 llama.cpp 提供的模型之上，模型可自行调用[内置工具](/features/extensibility/plugin/tools#built-in-system-tools-nativeagentic-mode)，并支持 [MCP](/features/extensibility/mcp) 服务器、[子智能体](/features/chat-conversations/chat-features/subagents)、[计时器](/features/chat-conversations/chat-features/timers) 和[自动化](/features/chat-conversations/chat-features/automations)
- **几乎一切都可以定制**：从按模型的提示词、工具、知识库和参数，到可以改变管道任意环节行为的[过滤器、管道、动作和事件函数](/features/extensibility/plugin/functions)，再加上主题、横幅和按群组的权限
- **丰富的 Web 平台**：包含完整聊天、对话、历史、组织和搜索
- **知识库与 RAG**：13 个向量数据库、8 个提取引擎，以及带重排序的混合搜索
- **多提供商支持**：可以将 llama.cpp 模型与 OpenAI、Anthropic、Google 等一起使用
- **团队平台**：包含频道、笔记、自动化、RBAC、SSO/OIDC/LDAP 和 SCIM 2.0
- **Open Terminal**：提供用于代码执行的完整计算环境
- **多用户支持**：从一个人到数千人

## 何时使用哪一个 {#when-to-use-each}

**使用 Llama app**：如果你希望轻松下载模型、在桌面上进行本地聊天，并接入其他应用。它内置的聊天可能已经够用。

**使用 llama.cpp CLI**：如果你需要直接控制推理、编写脚本或部署服务器。当前的命令包括用于终端聊天的 `llama cli`，以及用于 HTTP API 和浏览器界面的 `llama serve`。[CLI 文档](https://llama.app/docs/cli)

**再加上 Open WebUI**：如果你需要共享知识库、团队访问与权限、自定义工作流，或在同一工作区同时使用本地和云端提供商。它通过兼容 OpenAI 的 API 连接到 Llama app 或你自己的 llama.cpp 服务器。

## 将它们一起使用 {#use-them-together}

使用 **Llama app** 时，下载一个模型并让应用保持运行。它默认的 API 基础 URL 是 `http://localhost:9931/v1`。[Llama API 详情](https://llama.app/docs/api)

如果你想**手动启动服务器**，用显式端口启动一个本地 GGUF 模型：

```bash
llama serve -m /path/to/your-model.gguf --port 9931
```

如果你的安装提供了独立的 `llama-server` 二进制文件，请改用 `llama-server -m /path/to/your-model.gguf --port 9931`。

在 Open WebUI 管理员区域中，打开**设置 → 连接 → OpenAI → 添加连接**：

- **URL：** Open WebUI 直接运行在同一台机器上时用 `http://localhost:9931/v1`。端口不同则使用你配置的端口。
- **Auth：** 无密钥服务器选**无**；有密钥则选 **Bearer** 并填入服务器上配置的密钥。
- **Provider：** 在**高级设置**下选择 `llama.cpp`，以启用 Open WebUI 的本地模型管理功能。

保存连接并选择一个模型。模型管理与故障排查参见[连接指南](/getting-started/quick-start/connect-a-provider/starting-with-llama-cpp#step-4-connect-llamacpp-to-open-webui)。

:::note Docker 中的 Open WebUI
在容器内部，`localhost` 指的是该容器本身。在 Docker Desktop 上，请使用 `http://host.docker.internal:9931/v1`，并确保服务器接受来自 Docker 的连接。手动启动的服务器可以使用 `--host 0.0.0.0`；请将访问限制在可信客户端，并在允许从回环地址之外访问时配置 `--api-key`。在 Linux 上，可能需要使用主机网络或 host-gateway 映射。参见[连接故障排查](/troubleshooting/connection-error)。
:::

## 常见问题 {#frequently-asked-questions}

**llama.cpp 有官方桌面应用吗？**
有。[Llama app](https://llama.app/) 是 llama.cpp 团队和 Hugging Face 推出的官方桌面应用，提供 Mac 和 Windows 11 版本。它管理本地模型并打开内置的浏览器聊天界面。Linux 用户可以使用 CLI 和 Web 界面。

**我可以把 Llama app 或 llama-server 连接到 Open WebUI 吗？**
可以。两者都公开与 OpenAI 兼容的 API。对于直接运行在同一台机器上的 Open WebUI，Llama app 请添加 `http://localhost:9931/v1`，或使用你服务器配置的端口。无密钥服务器请选择 **Auth: None**。Docker 部署需要容器可访问的地址。

**Open WebUI 支持 llama-server 的多模型路由吗？**
支持。Open WebUI 会列出路由器 `/v1/models` 端点所公布的模型。选中某个模型进行推理时，路由器会按需加载该模型。

**llama.cpp 免费吗？**
免费。llama.cpp 以及官方的 [Mac](https://github.com/ggml-org/Llama-macOS) 和 [Windows](https://github.com/ggml-org/Llama-Windows) 应用均免费且采用 MIT 许可证。下载的模型各自拥有自己的许可证。

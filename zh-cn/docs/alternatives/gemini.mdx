# Open WebUI 与 Gemini {#open-webui--gemini}

*最后更新：2026 年 8 月*

[Gemini](https://gemini.google.com/) 将 Google 的 AI 研究融入消费产品，具有强大的多模态能力（文本、视觉、音频、代码）、慷慨的上下文窗口，以及与 Google Workspace 的自然集成。Gemini 3.5 Pro 是可用于代码和复杂任务的最强大的模型之一。

商用 · 免费层可用

---

## Gemini 擅长的领域 {#what-gemini-does-well}

- **多模态实力**，跨文本、图像、音频、视频和单一模型中的代码
- **Google Workspace 集成**，与 Gmail、Docs、Drive 和其他 Google 工具自然协作
- **Gems** 用于创建具有特定指令和行为的自定义 AI 角色
- **NotebookLM** 用于将文档转变为交互式学习指南和音频概览
- **深度研究**，进行多步骤研究并生成全面报告
- **慷慨的上下文窗口**，Gemini 3.5 Pro 可处理大型文档和代码库
- **竞争性 API 定价**，是高质量模型中最具成本效益的 API 之一
- **代码生成**，其中 Gemini 3.5 Pro 是代码任务中最强的之一
- **Google 搜索基础**，由 Google 搜索基础设施支持的回应
- **零设置**，通过您的 Google 帐户立即可用

---

## Open WebUI 擅长的领域 {#what-open-webui-does-well}

- **完整的 Agentic 平台**：模型可自行调用[内置工具](/features/extensibility/plugin/tools#built-in-system-tools-nativeagentic-mode)，并支持 [MCP](/features/extensibility/mcp) 服务器、[子智能体](/features/chat-conversations/chat-features/subagents)、[计时器](/features/chat-conversations/chat-features/timers) 和[自动化](/features/chat-conversations/chat-features/automations)，以同样的方式驱动 Gemini 和其他所有模型
- **几乎一切都可以定制**：从按模型的提示词、工具、知识库和参数，到可以改变管道任意环节行为的[过滤器、管道、动作和事件函数](/features/extensibility/plugin/functions)，再加上主题、横幅和按群组的权限
- **任何模型，一个界面**：可以*同时*使用 Gemini、Claude、GPT-5.6 和本地模型
- **自托管**，平台本身运行在你自己的基础设施上
- **知识库与 RAG**：用先进检索构建持久知识库
- **团队平台**：包含频道、笔记、自动化、RBAC、SSO/OIDC/LDAP 和 SCIM 2.0
- **Open Terminal**：提供完整的沙箱计算环境

## 何时使用每一个 {#when-to-use-each}

**选择 Gemini** 如果您生活在 Google 生态系统中，并希望 AI 与 Gmail、Docs、Drive 和搜索自然集成。NotebookLM 和深度研究是独特的功能，其他地方没有直接等价物。API 定价也是最具竞争力的之一。

**选择 Open WebUI** 如果您想在其他提供商旁边使用 Gemini、需要持久知识库，或想自托管。Open WebUI 连接到 Google AI API，所以您仍然可以获得 Gemini 的模型。

**两者都使用**。直接使用 Gemini 获得 Google Workspace 集成和 NotebookLM。将 Open WebUI 连接到 Google AI API，在一个界面中使用 Gemini 模型与 Claude、OpenAI 和本地模型并行。

## 通过 Open WebUI 使用 Gemini {#use-gemini-through-open-webui}

Gemini 模型通过 Google AI API 在 Open WebUI 中可用。您可以在连接的其他模型旁边使用 Gemini 的多模态能力。

**如何连接：**

1. 从 [aistudio.google.com](https://aistudio.google.com/) 获取 API 密钥
2. 在 Open WebUI 中，转到 **Settings → Connections**（管理员区域）
3. 使用基础 URL `https://generativelanguage.googleapis.com/v1beta/openai` 和您的 Google AI API 密钥添加新连接
4. Gemini 模型将出现在您的模型选择器中

:::warning 此端点上的工具需要额外设置
Google 的 OpenAI 兼容层使用的工具调用格式与 OpenAI 兼容客户端所期望的并不相同，因此使用工具的那一轮可能返回一条空的 assistant 消息。这会影响 Memory 等内置工具。请在模型的高级参数中把 **Function Calling** 设为 **Legacy**，或者通过 LiteLLM、OpenRouter 之类的网关来路由 Gemini。参见[模型使用工具时回复为空](/troubleshooting/connection-error#blank-replies-when-the-model-uses-a-tool)以及[OpenAI 兼容提供商指南](/getting-started/quick-start/connect-a-provider/starting-with-openai-compatible)。
:::

## 常见问题 {#frequently-asked-questions}

**我可以在 Open WebUI 中使用 Gemini 吗？**
可以。在设置中添加您的 Google AI API 密钥，Gemini 模型将出现在模型选择器中。

**我可以自托管 Gemini 吗？**
不能自托管 Gemini 本身，但您可以通过 Google AI API 在 Open WebUI 中使用 Gemini 模型。Open WebUI 在您的基础设施上运行，尽管 API 调用仍然去 Google。

**我可以同时使用 Gemini 和 Claude 吗？**
可以，Open WebUI 支持同时连接多个提供商。

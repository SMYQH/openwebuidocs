# Open WebUI & AnythingLLM {#open-webui--anythingllm}

*最后更新时间：2026 年 9 月*

[AnythingLLM](https://anythingllm.com/)（由 Mintplex Labs 开发）是我们在本地 AI 领域最喜爱的项目之一。创建一个工作区，添加你的文档，然后就能结合这些知识开始对话。工作区模型把每个项目的文档和对话放在一起，是组织工作的好方式。桌面应用让在自己的机器上运行 AI 变得轻松，无需另行搭建服务器。团队把这些部分打磨成一个容易上手的体验，做得非常出色。

他们的智能体工具同样值得探索：你可以使用内置技能、连接 MCP 服务器、编写自定义技能，并构建把模型指令与 API 调用、文件操作组合起来的流程。模型提供商、嵌入模型和向量数据库都可配置，因此有足够空间把它调成你自己的样子。接口设计用心与实用的灵活性相结合，是我们如此喜欢 AnythingLLM 的重要原因。Mintplex Labs 和贡献者们打造了一个我们乐于推荐的项目，我们对他们的工作怀有敬意。

[网站](https://anythingllm.com/) · [文档](https://docs.anythingllm.com/) · [GitHub](https://github.com/Mintplex-Labs/anything-llm) · [MIT 许可证](https://github.com/Mintplex-Labs/anything-llm/blob/master/LICENSE)

## AnythingLLM 的优势 {#what-anythingllm-does-well}

- **文档问答**：把文档带进对话，就其内容提问。
- **工作区模型**：把知识库和对话整理到相互独立的项目中。
- **嵌入定制**：可控制分块、重叠和嵌入模型的选择，从而塑造文档为检索所做的准备方式。
- **向量数据库选择**：集成包括 LanceDB、Chroma、Milvus、Pinecone、Qdrant 和 Weaviate，为文档嵌入的存储和检索提供多种选择。
- **模型选择**：支持本地和云端提供商，包括 Ollama、OpenAI、Anthropic、Google、Azure 和 Bedrock，让人们可以按偏好使用模型。
- **桌面应用**：面向 macOS、Windows 和 Linux 的独立本地体验，无需 Docker 或服务器。
- **自托管与云部署**：Docker 和托管选项为个人和团队提供了多种使用方式。
- **本地运行**：使用本地模型和嵌入，在自己的硬件上处理文档。
- **智能体与工具**：内置用于文档检索、网页浏览等任务的技能，并支持自定义技能和 MCP 连接。
- **智能体流程**：工作流可以串联网页抓取、API 调用、模型指令和文件操作等步骤。
- **音频与图像**：语音转文字、文字转语音和图像生成，让你在输入文字之外也能与 AI 交互。
- **多用户访问**：Docker 版本支持基于角色的权限，便于共享部署。
- **社区贡献**：团队和贡献者共享的代码、文档和想法。

有关各部署方式的功能与安装细节，请查阅 [AnythingLLM 文档](https://docs.anythingllm.com/)。

## Open WebUI 的优势 {#what-open-webui-does-well}

- **智能体与定时工作**：[内置工具](/features/extensibility/plugin/tools#built-in-system-tools-nativeagentic-mode)、[MCP 服务器](/features/extensibility/mcp)、[子智能体](/features/chat-conversations/chat-features/subagents)、[计时器](/features/chat-conversations/chat-features/timers)和[自动化](/features/chat-conversations/chat-features/automations)。
- **自定义能力**：按模型的提示词、工具、知识和参数，以及[过滤器、管道、动作和事件函数](/features/extensibility/plugin/functions)、主题、横幅和按群组的权限。
- **文档检索**：向量数据库和提取引擎集成、混合 BM25 与向量搜索、交叉编码器重排序以及智能体检索。
- **多种工作方式**：聊天、笔记、频道、自动化、Open Terminal、语音/视频通话和图像生成。
- **团队访问**：用于协作的频道、基于角色的访问控制、SSO/OIDC/LDAP 和 SCIM 2.0。
- **模型配置**：把模型与说明、工具、知识和参数组合起来。
- **部署与运维**：Kubernetes、水平扩展、Redis 后端会话、OpenTelemetry 和分析。

## 何时选择各个平台 {#using-both}

**选择 AnythingLLM**（如果）您主要想与文档对话。工作区模型可以清晰地分离不同项目，桌面应用使其无需任何服务器设置即可轻松上手。

**选择 Open WebUI**（如果）您需要更广泛的平台，包括团队协作、多提供商支持、扩展性或企业功能以及文档问答。

**他们解决不同的问题。** AnythingLLM 专注于使文档问答尽可能简单。Open WebUI 采用更广阔的视角，包括聊天、知识、协作和工具。两者都擅长各自的领域。

## 常见问题 {#frequently-asked-questions}

**AnythingLLM 和 Open WebUI 如何比较？**
AnythingLLM 使用其工作区模型专注于文档问答。Open WebUI 也有知识库、团队功能、扩展性和多提供商支持。它们各有优势。

**AnythingLLM 是免费的吗？**
是的。AnythingLLM 采用 MIT 许可证。有免费桌面应用和自托管 Docker 版本。

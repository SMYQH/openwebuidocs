# Open WebUI 与 Claude {#open-webui--claude}

*最后更新：2026 年 8 月*

[Claude](https://claude.ai/) 由 Anthropic 推出，凭借细致的写作、在长上下文中依然稳健的推理，以及便于将成果用于实际工作的产品体验，赢得了忠实用户。我们也是其中一员，每天都在使用 Claude。模型研究、长上下文工程、安全工作、产品上的克制以及开发者工具都体现在产品之中。Artifacts 让输出更易检视和打磨，Claude Code 把 Claude 带进了真实的开发流程，MCP 则为整个生态提供了把模型与工具、数据连接起来的一套通用语言。

Anthropic 团队推动了整个生态的发展。Claude 让细致的分析、可编辑的输出、智能体编程以及工具与数据的连接成为与 AI 协作的自然组成部分，也展示了一个聚焦于模型与产品的体验可以有多出色。当团队希望在自己的模型、知识、工具和工作流旁边使用 Claude 时，Open WebUI 正好与之契合。

商用 · 提供免费版

## Claude 擅长的领域 {#what-claude-does-well}

- **写作和推理**，具有周到、细致的回应和仔细的分析
- **扩展思考**，实时展示复杂问题的分步推理
- **大规模上下文窗口**，高达 200k tokens，用于处理大型文档和代码库
- **Artifacts** 用于对话旁的交互输出（代码、文档、可视化）
- **Claude Code** 用于直接在终端使用智能体编程
- **计算机使用**，让 Claude 与桌面应用和网络界面交互
- **MCP（模型上下文协议）**，Anthropic 创建的标准化 AI 工具与数据源连接的方式
- **安全优先设计**，通过 Anthropic 的宪法 AI 方法
- **强大的代码能力**，具有出色的代码生成、审查和调试
- **Projects** 用于组织具有持久上下文和指令的对话

## Open WebUI 擅长的领域 {#what-open-webui-does-well}

- **完整的 Agentic 平台**：模型可自行调用[内置工具](/features/extensibility/plugin/tools#built-in-system-tools-nativeagentic-mode)，并支持 [MCP](/features/extensibility/mcp) 服务器、[子智能体](/features/chat-conversations/chat-features/subagents)、[计时器](/features/chat-conversations/chat-features/timers) 和[自动化](/features/chat-conversations/chat-features/automations)，以同样的方式驱动 Claude 和其他所有模型
- **几乎一切都可以定制**：从按模型的提示词、工具、知识库和参数，到可以改变管道任意环节行为的[过滤器、管道、动作和事件函数](/features/extensibility/plugin/functions)，再加上主题、横幅和按群组的权限
- **任何模型，一个界面**：可以*同时*使用 Claude、GPT-5.6、Gemini 和本地模型
- **自托管**，平台本身运行在你自己的基础设施上
- **知识库与 RAG**：用先进检索构建持久知识库
- **团队平台**：包含频道、笔记、自动化、RBAC、SSO/OIDC/LDAP 和 SCIM 2.0
- **Open Terminal**：提供完整的沙箱计算环境
- **免费社区版**：在你自己的基础设施上支持无限用户

## 如何选择 {#when-to-use-each}

**选择 Claude**：如果你重视写作和推理体验，特别是处理长上下文、审查代码或做细致分析。扩展思考尤其适合复杂问题。Claude Code 和计算机操作功能拓宽了 AI 可以自主完成的任务范围。

**选择 Open WebUI**：如果你希望在同一界面中同时使用 Claude 和其他模型，构建持久化知识库，或让团队协作。Open WebUI 也支持通过 API 使用 Claude 的扩展思考。

**两者都用。** 把 Open WebUI 连接到 Anthropic API，用 Claude 做深度分析，同时用 GPT-5.6 处理其他任务，用本地模型处理隐私敏感工作。如果需要 Artifacts、Projects 或计算机操作功能，可直接使用 claude.ai。

## 通过 Open WebUI 使用 Claude {#use-claude-through-open-webui}

Claude 模型通过 Anthropic API 在 Open WebUI 中可用。许多 Open WebUI 用户把 Claude 作为主要模型，将 Claude 的推理能力与 Open WebUI 的知识库、工具和团队功能结合起来。

**如何连接：**

1. 从 [console.anthropic.com](https://console.anthropic.com/) 获取 API 密钥
2. 在 Open WebUI 管理员区域打开**设置 → 连接**
3. 使用你的 Anthropic API 密钥添加新连接，基础 URL 为 `https://api.anthropic.com/v1`
4. Claude 模型将出现在模型选择器中

你可以用 Claude 进行复杂分析和写作，同时通过 Ollama 把更简单的任务路由到本地模型，所有这些都在同一界面中。

## 常见问题 {#frequently-asked-questions}

**我可以自托管 Claude 吗？**
不能自托管 Claude 本身，但你可以通过 Anthropic API 在 Open WebUI 中使用 Claude 模型。Open WebUI 运行在你自己的基础设施上，但 API 请求仍会发送至 Anthropic。

**我可以在 Open WebUI 中使用 Claude 吗？**
可以。在设置中添加你的 Anthropic API 密钥，Claude 模型就会出现在模型选择器中。

**我可以同时使用 Claude 和 ChatGPT 吗？**
可以，Open WebUI 支持同时连接多个提供商。

**Open WebUI 支持 Claude 的扩展思考吗？**
支持。只要模型提供扩展思考，就可以使用该功能，例如通过 Anthropic API 接入的 Claude。

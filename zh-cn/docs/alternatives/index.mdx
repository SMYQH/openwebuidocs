AI 领域有很多出色的项目，我们乐见其成。工具越多，就有越多人能以适合自己的方式使用 AI。

我们常被问到“还有什么选择？”，所以整理了这份清单。如果 Open WebUI 不太适合你的场景，我们也乐于推荐这些工具。我们用过其中一些，与一些项目并肩开发，也欣赏另一些项目做得出色的地方。清单上的工具都可以免费上手。

## 如何选择 {#how-to-choose}

- **运行本地模型？** 从 [Ollama](/alternatives/ollama) 或 [llama.cpp](/alternatives/llama-cpp) 开始，两者都可与 Open WebUI 配合使用
- **想要桌面应用？** [Llama app](/alternatives/llama-cpp#llama-app-local-ai-in-a-few-clicks) 把 llama.cpp 带到 Mac 菜单栏和 Windows 11 系统托盘，支持模型下载和浏览器聊天。[LM Studio](/alternatives/lm-studio) 和 [Jan](/alternatives/jan) 同样是优秀的独立选项
- **需要文档问答？** [AnythingLLM](/alternatives/anythingllm) 使私有 RAG 变得简单
- **多供应商聊天？** [LibreChat](/alternatives/librechat) 在这方面做得很好
- **构建 AI 工作流？** [Dify](/alternatives/dify) 有可视化工作流设计器
- **想要开箱即用的 AI？** [ChatGPT](/alternatives/chatgpt)、[Claude](/alternatives/claude) 和 [Gemini](/alternatives/gemini) 都是世界领先的 AI 产品：拥有前沿模型和成熟界面，迭代快，几乎无需配置。它们的模型也可以通过 API 在 Open WebUI 中使用。

## 常见问题 {#frequently-asked-questions}

**Open WebUI 免费吗？**
免费。社区版对无限用户免费。也提供企业计划。

**我能自托管 Open WebUI 吗？**
能。Open WebUI 可以通过 Docker、Kubernetes、pip 或桌面应用在您自己的基础设施上运行。您的数据保留在您的硬件上。

**Open WebUI 支持哪些模型？**
Open WebUI 连接任何与 OpenAI 兼容的 API，加上原生 Ollama 集成。这包括 OpenAI、Anthropic、Google、Azure、AWS Bedrock、llama.cpp、LM Studio 和数百个其他提供商。

# Open WebUI 与 ChatGPT {#open-webui--chatgpt}

*最后更新：2026 年 8 月*

[ChatGPT](https://chat.openai.com/) 由 OpenAI 推出，让现代 AI 走进数亿人的日常生活，也设定了会话式 AI 体验应有的标准。它改变了世界看待 AI 的方式，并且持续带来启发。我们每天都在使用它，也从背后的工作中学习：研究、工程、设计、安全工作、基础设施、产品决策和支持，这些工作让如此大规模的产品依然自然易用。GPT-5.6 系列、ChatGPT agent、ChatGPT Images 以及持续不断的产品创新让 ChatGPT 始终处于前沿，说实话，它也在推动我们把 Open WebUI 做得更好。

Open WebUI 诞生于 ChatGPT 帮助开创的品类之中。OpenAI 的人让 AI 变得有用、易用，值得带进日常工作，而不只是实验室和演示。他们的工作为这个领域的每一位建设者提高了标准。Open WebUI 面向那些希望自己运行界面、连接自己选择的模型、让整套技术栈适应自身环境的个人和团队。

商用 · 提供免费版

## ChatGPT 擅长的领域 {#what-chatgpt-does-well}

- **前沿模型**，包括 GPT-5.6 系列
- **写作与代码块**，用于在对话中进行长文起草、编辑和代码工作
- **Projects**，用于组织具有持久上下文和自定义指令的对话
- **深度研究**，将来自多个来源的信息综合成全面报告
- **精致的体验**，来自多年的界面迭代
- **GPT 商店**，包含社区构建的自定义 GPT 生态系统
- **多模态**，具有视觉、语音、ChatGPT Images 和代码执行
- **记忆**，能够跨对话记住上下文
- **ChatGPT agent**，用于代理式网页浏览和任务自动化
- **企业版**，包含 SSO、管理控制和数据隐私承诺
- **零设置**，你注册并开始，无需安装

## Open WebUI 擅长的领域 {#what-open-webui-does-well}

- **完整的 Agentic 平台**：模型可自行调用[内置工具](/features/extensibility/plugin/tools#built-in-system-tools-nativeagentic-mode)，并支持 [MCP](/features/extensibility/mcp) 服务器、[子智能体](/features/chat-conversations/chat-features/subagents)、[计时器](/features/chat-conversations/chat-features/timers) 和[自动化](/features/chat-conversations/chat-features/automations)，可自由选择模型，而不是绑定某一家厂商
- **几乎一切都可以定制**：从按模型的提示词、工具、知识库和参数，到可以改变管道任意环节行为的[过滤器、管道、动作和事件函数](/features/extensibility/plugin/functions)，再加上主题、横幅和按群组的权限
- **自托管**，平台本身运行在你自己的硬件上
- **任何模型、任何提供商**：同一个界面中既能用你 API 账户可用的 OpenAI 模型，*也能*用 Claude *和* Gemini *以及*本地模型
- **知识库与 RAG**：用先进检索从你的文档中构建知识库
- **团队平台**：包含频道、笔记、自动化、RBAC、SSO/OIDC/LDAP 和 SCIM 2.0
- **Open Terminal**：提供完整的沙箱计算环境
- **免费社区版**：在你自己的基础设施上支持无限用户

## 如何选择 {#when-to-use-each}

**选择 ChatGPT**：如果你想直接体验 OpenAI 功能最完善的产品。无需安装，无需配置，注册即可开始。Projects、记忆、语音、ChatGPT agent、图像生成和深度研究等功能的原生体验非常出色，并在不断改进。

**选择 Open WebUI**：如果你想自托管，在一个界面中连接多个提供商，用文档构建知识库，或使用免费社区版内置的 RBAC 和 SSO 等团队功能。

**两者都用。** 很多人都这样做。把 Open WebUI 连接到 OpenAI API，在同一个地方把 OpenAI 模型与 Claude、Gemini 和本地模型一起使用。想要完整的 OpenAI 产品体验时直接使用 ChatGPT，需要自己的知识库、工具、权限或团队工作区时使用 Open WebUI。

## 通过 Open WebUI 使用 OpenAI 模型 {#use-openai-models-through-open-webui}

Open WebUI 连接到 OpenAI API，因此你 API 账户可用的 OpenAI 模型可以与 Open WebUI 的知识管理、工具和团队功能一起使用。

**如何连接：**

1. 从 [platform.openai.com](https://platform.openai.com/) 获取 API 密钥
2. 在 Open WebUI 管理员区域打开**设置 → 连接**
3. 使用你的 API 密钥添加新的 OpenAI 连接
4. 你 API 账户可用的 OpenAI 模型将出现在模型选择器中

许多用户在同一界面中使用 OpenAI 模型进行复杂推理，同时通过 Ollama 使用本地模型处理隐私敏感任务。

## 常见问题 {#frequently-asked-questions}

**我可以自托管 ChatGPT 吗？**
ChatGPT 本身不能，但 Open WebUI 连接到 OpenAI API，所以你可以使用 API 账户可用的 OpenAI 模型。Open WebUI 在你的基础设施上运行，但 API 请求仍会发送至 OpenAI。

**我可以在 Open WebUI 中使用 OpenAI 模型吗？**
可以。在设置中添加你的 OpenAI API 密钥，API 账户可用的 OpenAI 模型就会出现在模型选择器中。

**Open WebUI 是 ChatGPT 替代品吗？**
Open WebUI 可以连接到 OpenAI API，所以你可以使用 API 账户可用的 OpenAI 模型。Open WebUI 在你自己的基础设施上运行，但 API 请求仍会发送给提供商。它还支持连接到其他提供商。

**我可以同时使用 ChatGPT 和本地模型吗？**
可以。许多用户在同一个 Open WebUI 界面中使用 OpenAI 处理复杂推理，同时通过 Ollama 使用本地模型处理隐私敏感任务。

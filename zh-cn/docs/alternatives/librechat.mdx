# Open WebUI 与 LibreChat {#open-webui--librechat}

*最后更新时间：2026 年 8 月*

[LibreChat](https://www.librechat.ai/) 是我们很认可的项目之一。它支持与多个提供商的模型聊天，提供完善的身份验证和并排模型比较功能，并专注于做好基本的聊天体验。该项目采用 MIT 许可证，由 Danny 和社区积极维护。

[GitHub](https://github.com/danny-avila/LibreChat) · [MIT 许可证](https://github.com/danny-avila/LibreChat/blob/main/LICENSE)

---

## LibreChat 的优势 {#what-librechat-does-well}

- **多提供商聊天**，为 OpenAI、Anthropic、Google、Azure、Ollama 和任何 OpenAI 兼容 API 提供统一界面
- **模型比较**，在单个对话中并排查看来自不同模型的响应
- **预设系统**，用于保存和快速切换模型配置和系统提示
- **Artifacts**，用于内联渲染代码输出、文档和可视化
- **身份验证**，包括 LDAP、SSO 和社交登录支持
- **内置代码解释器**，用于支持的模型
- **提示缓存**，用于减少重复交互时的 API 成本
- **聚焦聊天**，聊天界面好用，不增加不必要的复杂度
- **活跃开发**，具有反应迅速的维护者和参与度高的社区
- **MIT 许可证**

---

## Open WebUI 的优势 {#what-open-webui-does-well}

- **完整的 Agentic 平台**：模型可自行调用[内置工具](/features/extensibility/plugin/tools#built-in-system-tools-nativeagentic-mode)，并支持 [MCP](/features/extensibility/mcp) 服务器、[子智能体](/features/chat-conversations/chat-features/subagents)、[计时器](/features/chat-conversations/chat-features/timers) 和[自动化](/features/chat-conversations/chat-features/automations)，用于委派任务和定时工作
- **几乎一切都可以定制**：从按模型的提示词、工具、知识库和参数，到可以改变管道任意环节行为的[过滤器、管道、动作和事件函数](/features/extensibility/plugin/functions)，再加上主题、横幅和按群组的权限
- **超越聊天的平台**：包含笔记、频道、自动化、Open Terminal、语音/视频通话、图像生成和日历
- **知识库与 RAG**：13 个向量数据库、8 个提取引擎、带重排序的混合搜索和智能体检索
- **模型代理**：为任何模型加上自定义指令、工具、知识和参数
- **企业功能**：包含 RBAC、SSO/OIDC/LDAP、SCIM 2.0、分析仪表板和评估竞技场
- **灵活部署**：通过 Docker、Kubernetes、pip 或桌面应用，支持水平扩展和 OpenTelemetry

## 何时选择各个平台 {#when-to-use-each}

**选择 LibreChat**：如果你想要简洁的多提供商聊天界面和强大的模型比较功能。预设让你轻松切换配置，MIT 许可证也提供了很大的灵活性。

**选择 Open WebUI**：如果你需要功能更广的平台，包括知识库、团队协作工具、Python 扩展，或 SCIM 和分析等企业功能。

**同时运行两者。** 它们连接到相同的后端。一些团队使用 LibreChat 进行快速个人聊天，使用 Open WebUI 进行带有知识库和工具的协作工作。

---

## 一起使用它们 {#use-them-together}

两个项目都连接到相同的后端（Ollama、OpenAI 等），因此您可以并排运行两者。一些团队使用 LibreChat 进行快速个人聊天，使用 Open WebUI 进行团队协作和知识工作。

## 常见问题 {#frequently-asked-questions}

**LibreChat 和 Open WebUI 如何比较？**
LibreChat 在多提供商聊天界面方面表现非常好。Open WebUI 还包括知识库、团队协作、扩展性和企业功能。范围不同，两者都值得关注。

**LibreChat 是免费的吗？**
是的。LibreChat 采用 MIT 许可证，可免费自托管。

**我可以同时使用 LibreChat 和 Open WebUI 吗？**
是的。两者都连接到相同的后端（Ollama、OpenAI 等），因此您可以并排运行两者。
